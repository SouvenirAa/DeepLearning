# 一、一些基础知识

## 1、梯度下降算法的原理

**损失函数对参数的梯度，表示的是使得**💥**损失函数增加**的方向。**

但是在神经网络训练中，我们用的是 **梯度的负方向**（即 **下降方向**）来更新参数，使得损失函数**减小**。

------

🧠 为什么这么说？

设：

- 损失函数记为 $L(\theta)$，其中 $\theta$ 是模型参数；
- $\nabla_\theta L$ 是损失函数对参数的梯度。

那么：

- **$\nabla_\theta L$ 给出的方向是“使损失增加最快”的方向**；

- 我们用 **梯度下降法（Gradient Descent）** 来更新参数：
  $$
  \theta \leftarrow \theta - \eta \cdot \nabla_\theta 
  $$
  其中 $\eta$ 是学习率。

所以我们是 **朝着梯度的反方向走**，从而**最小化损失函数**。

------

📘 举个例子（直观理解）

假设你站在一个山谷里（损失函数的最低点），梯度就是告诉你“哪个方向是坡最陡的上坡”。但你不想上山，你想走到山谷底部，所以你反方向走，也就是“梯度的负方向”。

------

🤔 总结一行话：

**梯度本身表示“上升最快方向”，我们用的是它的反方向来“最小化损失函数”。**

## 2、交叉熵

### 2.1、交叉熵

“交叉熵”（Cross Entropy）是机器学习和信息论中常用的一个概念，主要用于衡量两个概率分布之间的差异，尤其是在分类问题中评估模型预测的概率分布与真实标签分布的差距。

------

#### 📘 2.1.1 基本定义

假设：

- 真正的分布为 $P$
- 预测的分布为 $Q$

那么交叉熵的定义为：
$$
H(P, Q) = -\sum_{x} P(x) \log Q(x)
$$
也可以理解为：用预测分布 $Q$ 来描述真实分布 $P$ 所需要的“平均信息量”。

------

#### 📊 2.1.2 分类问题中的应用（尤其是神经网络）

在实际机器学习中，比如一个分类问题中，我们用 one-hot 向量表示真实标签 $y$，神经网络输出预测概率 $\hat{y}$，则交叉熵损失函数是：
$$
\text{Loss} = -\sum_{i} y_i \log(\hat{y}_i)
$$
对于二分类问题，简化形式是：
$$
\text{Loss} = -[y \log(\hat{y}) + (1 - y)\log(1 - \hat{y})]
$$
其中：

- $y$ 是真实标签（0 或 1）
- $\hat{y}$ 是模型预测为正类的概率

------

#### ✅ 2.1.3 交叉熵的意义和作用

- 如果模型预测得很好（$\hat{y}$ 很接近真实标签），交叉熵损失就很小。
- 如果预测偏离真实标签较远，交叉熵损失就会很大。
- 在深度学习中，交叉熵损失函数搭配 softmax 层常用于多分类问题。

------

#### 🔍 2.1.4 交叉熵 vs MSE（均方误差）

- MSE 更适用于回归问题，对概率预测不敏感；
- 交叉熵更适合处理概率预测问题，尤其在分类场景下更高效、收敛更快。

### 2.2、疑问

#### 2.2.1 真实标签 $y$可以有多个位置的值为1吗

✅ 一、多分类（**multi-class classification**）

**特点：**

- 每个样本只能属于一个类别。
- 标签 $y$ 是 **one-hot 向量**，只有一个位置为 1，其余为 0。

**例子：** 假设有三个类别：[猫、狗、鸟]，样本是“狗”，标签为：
$$
y = [0, 1, 0]
$$
**交叉熵损失形式：**
$$
\text{Loss} = -\sum_i y_i \log(\hat{y}_i)
$$
只有对应真实标签那一位会有非零贡献。

------

✅ 二、多标签分类（**multi-label classification**）

**特点：**

- 每个样本可以同时属于多个类别。
- 标签 $y$ 是 **多热向量（multi-hot vector）**，可以有多个 1。

**例子：** 图像中同时出现“猫”和“狗”：
$$
y = [1, 1, 0]
$$
这时你通常会使用 **sigmoid 函数** 来分别预测每一类的概率，而不是 softmax。交叉熵会对每一类分别计算：
$$
\text{Loss} = -\sum_i \left[ y_i \log(\hat{y}_i) + (1 - y_i)\log(1 - \hat{y}_i) \right]
$$
这就是多标签版本的交叉熵。

------

🔄 总结

| 分类类型   | 标签格式  | 可以多个1？ | 激活函数 | 损失函数             |
| ---------- | --------- | ----------- | -------- | -------------------- |
| 多分类     | One-hot   | ❌ 否        | Softmax  | 单个交叉熵           |
| 多标签分类 | Multi-hot | ✅ 是        | Sigmoid  | 每类交叉熵（逐元素） |

### 2.3 交叉熵损失的问题及解决方案

#### 🚨 1. **log(0)** 或 log(接近 0) → 无穷大 / NaN

- 如果模型预测中某个类别的概率是 **0 或接近 0**，而这个类别恰好是正确答案，那么就会出现：
  $$
  -\log(0) = +\infty
  $$
  
- 在 PyTorch 中，如果你直接 `torch.log(y_hat)` 而没有做安全处理，就有可能爆炸。

✅ **解决方法**：

- 给 `y_hat` 加一个非常小的常数：

  ```python
  torch.log(y_hat + 1e-9)
  ```

- 或者使用 PyTorch 提供的安全函数：

  ```python
  F.cross_entropy(logits, targets)  # 内部做了log_softmax + one_hot
  ```

✅ 举个你自己的代码例子：

你原来的交叉熵函数是这样的：

```python
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])
```

------

✅ 加上 epsilon 的写法如下：

```python
def cross_entropy_safe(y_hat, y, eps=1e-9):
    # 防止 log(0) 导致 NaN
    clipped_y_hat = y_hat.clamp(min=eps)
    return -torch.log(clipped_y_hat[range(len(y),), y])
```

------

📌 说明：

- `y_hat.clamp(min=eps)`：将 `y_hat` 中所有小于 `eps` 的值替换成 `eps`（如 1e-9）
  - 这样即使某类的预测概率为 0，实际值也变成了 `1e-9`，不会出现 `log(0)`
- `eps=1e-9` 是常见的安全阈值，你也可以调得更小或更大

------

🔁 示例对比：

```python
y_hat = torch.tensor([[1e-10, 0.999999999, 0.0]])
y = torch.tensor([2])
```

如果你用原版的 `cross_entropy`，会爆炸：

```python
- torch.log(y_hat[0, 2])  # log(0) → -inf
```

使用安全版本：

```python
loss = cross_entropy_safe(y_hat, y)
print(loss)  # 合理数值（不会是 nan 或 inf）
```

------

✅ 推荐实践建议：

- 如果你手动实现 softmax + cross_entropy，**一定要加 epsilon**。
- 如果你用的是 `torch.nn.CrossEntropyLoss()`，就 **不用加 epsilon**，因为它内部已经做了防护。

## 3、张量广播

广播（**broadcasting**）是 PyTorch 和 NumPy 等框架中用于处理不同形状张量之间运算的机制。它的核心思想是：在符合一定规则的前提下，将较小维度的张量**自动扩展**为较大的张量的形状，使它们可以进行逐元素运算。

------

✅ 广播的条件总结（适用于 PyTorch）

假设有两个张量 `A` 和 `B`，它们的形状分别为：

```python
A.shape = (a₁, a₂, ..., aₙ)
B.shape = (b₁, b₂, ..., bₘ)
```

1. **从尾维（右边）开始对齐**比较。
2. 如果两个维度相等，或者其中一个为 1，则可以广播。
3. 否则就报错。

如果维度数不同，前面缺失的维度会被自动补为 1。

------

📌 具体规则说明

- 从右往左（尾部）逐维比较。
- 每一维满足以下任一：
  - 相等
  - 其中一个是 1（可以扩展）
- 如果维度数量不一样，短的那个前面会自动补 1。

------

✅ 示例说明

示例 1：

```python
A: (3, 1)
B: (1, 4)
```

→ 广播后：

```python
A: (3, 4)
B: (3, 4)
```

示例 2：

```python
A: (5, 3, 1)
B:       (4,)
```

→ 补齐 B 为 `(1, 1, 4)`，结果广播为：

```
A: (5, 3, 4)
B: (5, 3, 4)
```

示例 3：不满足广播条件

```python
A: (2, 3)
B: (3, 2)
```

→ 对比：

```python
A: (2, 3)
B: (3, 2) ❌ 不满足任何维度
```

会报错：`RuntimeError: The size of tensor a (3) must match the size of tensor b (2) at non-singleton dimension X`

# 二、线性回归

## 1、从零实现

以下是从零开始实现 PyTorch 中线性回归的方法，包括代码和数学解释。

------

### 数学背景

线性回归模型的目标是通过拟合数据来预测目标变量 y。其模型公式为：
$$
y = Xw + b
$$
其中：

- X是输入特征矩阵（每一行是一个样本，每一列是一个特征），
- w 是权重向量（回归系数），
- b 是偏差项（常数项），
- y是目标变量。

为了训练模型，我们需要最小化一个损失函数（通常是均方误差损失），即：
$$
L(w, b) = \frac{1}{2m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2
$$
其中：
$$
\begin{array}{lcl}
- m 是样本数量，\\
- y_i 是真实值，\\
- \hat{y}_i = X_i w + b 是预测值。
\end{array}
$$
**梯度下降法** 用来更新模型参数 w 和 b，使得损失函数最小化。梯度更新公式为：
$$
w = w - \eta \cdot \frac{\partial L(w, b)}{\partial w}\\
b = b - \eta \cdot \frac{\partial L(w, b)}{\partial b}\\

其中 \eta 是学习率，控制每次更新的步长。
$$
学习率的设定不能太小也不能太大，太小导致收敛过慢，太大导致震荡

------

### PyTorch 代码实现

```python
function.py

import matplotlib   # 绘图
import random   # 用于生成随机数
import torch


# 人造数据集生成函数
def synthetic_data(w,b,num_examples):   # w是各个输入参数的权重，b是偏差
    """生成y=Xw+b+噪声"""
    X = torch.normal(0,1,(num_examples,len(w)))	#一行代表一个样本
    '''
    由于构造的真实w，b为
    true_w = torch.tensor([2, -3.4])
    true_b = 4.2
    w为一维张量，形状为(2,)，X为num_examples*2张量，所以X*w为形状为(num_examples,)一维张量
    y也为一维张量
    '''
    y = torch.matmul(X,w) + b   # 根据回归方程生成值
    y += torch.normal(0,0.01,y.shape)   # 右侧等式生成随机噪声
    return X,y.reshape(-1,1)    # 如果不加reshape，返回的y是一个一维的张量
# 定义一个生成小批量数据迭代器的函数
def data_iter(batch_size, features, labels):
    num_examples = len(features)    # 样本的总数
    indices = list(range(num_examples))     # 针对样本数量生成一个列表
    # 要使样本随机读取，打乱indices的顺序
    random.shuffle(indices)
    # for循环开始遍历，从0开始，一直到样本数量，每次迭代后i+batch_size
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(indices[i:min(i+batch_size, num_examples)])   # 小批量数据对应的索引
        yield features[batch_indices], labels[batch_indices]
# # 定义回归模型
def linreg(X, w, b):
    return torch.matmul(X, w) + b
# # 定义损失函数
def squared_loss(y_hat, y):
    return ((y_hat - y.reshape(y_hat.shape)) ** 2/2).mean()
# # 定义梯度下降优化算法
def sgd(params, learning_rate):
    """小批量随机梯度下降"""
    with torch.no_grad():
        for param in params:
            param -= learning_rate * param.grad
            param.grad.zero_()
```

```python
main.py

from function import synthetic_data, data_iter, linreg, squared_loss, sgd
import torch
from d2l import torch as d2l


# 生成人造模拟数据
true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = synthetic_data(true_w, true_b, 1000)

# d2l.set_figsize()
# d2l.plt.scatter(features[:,1].detach().numpy(), labels.detach().numpy(),1)
# d2l.plt.show()
#
# 定义超参数：学习率和迭代周期
learning_rate = 0.03
num_epochs = 3
# 定义初始的w和b
w = torch.normal(0, 0.01, size=(2,1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
batch_size = 10

for epoch in range(num_epochs):
    for x, y in data_iter(batch_size, features, labels):
        # 前向传播
        '''
        由于w为2*1矩阵，x为batc_size*2，所以x*w为batch_size*1，加上b的时候广播
        最终结果y_hat为batch_size*1，是一个二维张量
        '''
        y_hat = linreg(x, w, b)    # 当前小批量对应的预测值
        loss = squared_loss(y_hat, y)
        loss.backward()     # 反向传播
        sgd([w, b], learning_rate)
    with torch.no_grad():
        train_l = squared_loss(linreg(features, w, b), labels)
        print(f'epoch {epoch}, losss {float(train_l):f}')
```

------

### 解释与数学公式

#### 1. **数据生成：**

`synthetic_data(w, b, num_examples)` 函数根据给定的真实权重 w 和偏差 b 生成符合线性回归模型的数据，并加入一些随机噪声。
$$
y = Xw + b + \epsilon \\
$$
其中  $$\epsilon $$ 是噪声，服从正态分布 $$ \epsilon \sim \mathcal{N}(0, 0.01)$$。

#### 2. **线性回归模型：**

我们通过定义一个简单的线性回归模型来计算预测值 $$\hat{y}$$，公式为：
$$
\hat{y} = Xw + b
$$

#### 3. **损失函数：**

我们使用均方误差（MSE）作为损失函数，公式为：
$$
L(w, b) = \frac{1}{2m} \sum_{i=1}^{m} (y_i - \hat{y}_i)^2
$$
其中 m 为样本数量，$$y_i$$是真实值，$$\hat{y}_i $$是预测值。

#### 4. **梯度下降：**

梯度下降法用来优化损失函数，更新权重和偏差。梯度更新公式为：
$$
w = w - \eta \cdot \frac{\partial L(w, b)}{\partial w} \\
b = b - \eta \cdot \frac{\partial L(w, b)}{\partial b} \\
$$
其中 $$\eta$$ 是学习率，控制每次更新的步长。我们通过反向传播来计算损失函数相对于 w 和 b 的梯度。

#### 5. **训练过程：**

在训练过程中，我们采用 **小批量随机梯度下降**（SGD）来更新参数。每次从数据中获取一个小批量，通过计算该批量的损失和梯度来更新参数 w 和 b。

------

### 总结

- **线性回归** 的目的是通过找到合适的权重 w 和偏差 b 来最小化损失函数，从而得到最优的预测模型。
- 通过 PyTorch 提供的自动求导功能，我们可以轻松实现梯度下降来优化模型。
- 本代码从数据生成、模型定义、损失计算、梯度更新到训练过程，完整展示了线性回归的实现步骤。

使用这个代码，你可以清晰地理解线性回归模型是如何使用梯度下降进行训练和优化的。

## 2、简单实现

------

### 完整代码

```python
import numpy as np
import torch
from torch.utils import data
from d2l import torch as d2l
from torch import nn

# 定义初始参数
true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = d2l.synthetic_data(true_w, true_b, 1000) # 生成人工数据集

def load_array(data_arrays, batch_size, is_train=True):
    """构造一个PyTorch数据迭代器"""
    dataset = data.TensorDataset(*data_arrays)
    return data.DataLoader(dataset, batch_size, shuffle=is_train)

batch_size = 10
data_iter = load_array((features, labels), batch_size)

# 定义模型---单层神经网络
net = nn.Sequential(nn.Linear(2, 1))
# 定义初始的权重和偏差变量
net[0].weight.data.normal_(mean=0.0, std=0.01)
net[0].bias.data.fill_(0)
# 定义损失函数
loss = nn.MSELoss()
# 定义优化算法
trainer = torch.optim.SGD(net.parameters(), lr=0.03)

# 训练
num_epochs = 3
for epoch in range(num_epochs):
    for X, y in data_iter:
        l = loss(net(X), y)
        trainer.zero_grad()
        l.backward()
        trainer.step()
    l = loss(net(features), labels)
    print(f'Epoch {epoch}, loss: {l:f}')
```

------

### 代码解释

这段代码是使用 PyTorch 来实现一个简单的线性回归模型，并对模型进行训练。

### 1. 导入必要的库

```python
import numpy as np
import torch
from torch.utils import data
from d2l import torch as d2l
```

- `numpy` 是用于处理数组和数学计算的库，通常用于数据处理。
- `torch` 是 PyTorch 的核心库，提供了张量操作和深度学习的各种功能。
- `data` 是 PyTorch 提供的用于加载数据的工具。
- `d2l` 是《动手学深度学习》中的工具包，用于生成数据和一些常见操作的辅助函数。

### 2. 创建训练数据

```python
true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = d2l.synthetic_data(true_w, true_b, 1000)
```

- `true_w` 和 `true_b` 是线性回归模型的真实参数，`true_w` 是权重，`true_b` 是偏置。

- `d2l.synthetic_data` 生成了 1000 个样本的数据，`features` 是特征，`labels` 是目标值。这里模拟的任务是线性回归，数据遵循如下关系：
  $$
  y = w_1 \cdot x_1 + w_2 \cdot x_2 + b	\\
  
  其中 x_1 和 x_2 是输入特征，w_i 和 b_i 是模型的真实参数。
  $$
  

### 3. 定义数据加载函数

```python
ef load_array(data_arrays, batch_size, is_train=True):  #@save
    """构造一个PyTorch数据迭代器"""
    dataset = data.TensorDataset(*data_arrays)
    return data.DataLoader(dataset, batch_size, shuffle=is_train)
```

- 这个函数用来将数据 `data_arrays` 转换成 PyTorch 的数据迭代器 `DataLoader`。

- `TensorDataset` 是将数据转换为 PyTorch 数据集的容器。

  1. **封装数据**：

     - `TensorDataset` 将多个张量（如 `features` 和 `labels`）组合成一个数据集，使它们能成对访问，类似于 Python 的 `zip(features, labels)`。

     - 例如：

       ```python
       dataset = TensorDataset(features, labels)
       # 相当于：
       # dataset[i] = (features[i], labels[i])
       ```

  2. **方便 `DataLoader` 进行批处理**：

     - `DataLoader` 需要一个 `Dataset` 对象才能工作，它负责：
       - **分批（batch）**：每次返回 `batch_size` 个样本。
       - **随机打乱（shuffle）**：如果 `is_train=True`，则每个 epoch 都会打乱数据顺序，防止模型学习到数据的顺序信息。
       - **并行加载（multi-processing）**：可设置 `num_workers` 加速数据加载。

  3. **`\*data_arrays` 的作用**：

     - `*data_arrays` 是 Python 的**解包操作**，假设 `data_arrays = (features, labels)`，那么：

       ```python
       TensorDataset(*data_arrays)  
       # 等价于：
       TensorDataset(features, labels)
       ```

- `DataLoader` 是 PyTorch 提供的一个用于加载数据的工具，能够方便地按批次加载数据（mini-batch），支持批量训练。

- `batch_size` 是每个小批量的大小，`is_train` 决定是否打乱数据（通常训练时需要打乱数据）。

### 4. 设置数据迭代器并查看一批数据

```python
batch_size = 10
data_iter = load_array((features, labels), batch_size)
next(iter(data_iter))
```

- `batch_size` 设置每个批次的数据大小为 10。
- `data_iter` 是数据加载器，用来按批次加载训练数据。
- `next(iter(data_iter))` 是获取数据迭代器中的一批数据，返回的是一个元组 `(X_batch, y_batch)`，其中 `X_batch` 是一个 10x2 的矩阵，`y_batch` 是一个包含 10 个标签的向量。
- pycharm中通过`batch = next(iter(data_iter))`，然后输出batch来查看一个批次的数据

### 5. 定义模型

```python
from torch import nn

net = nn.Sequential(nn.Linear(2, 1))
```

- `nn` 是 PyTorch 的神经网络模块，提供了很多神经网络相关的层、损失函数等。
- `net` 是模型的定义，使用了 `nn.Sequential` 使得模型结构变得简洁。这里定义了一个包含一层 `Linear` 的模型。
  - `Linear(2, 1)` 表示输入有 2 个特征（`2`），输出是一个值（`1`）。这就是典型的线性回归模型。

### 6. 初始化参数

```python
net[0].weight.data.normal_(0, 0.01)
net[0].bias.data.fill_(0)
```

- `net[0]` 代表模型的第一层（即 `Linear` 层）。
- `weight.data.normal_(0, 0.01)` 使用正态分布来初始化权重，均值为 0，标准差为 0.01。
- `bias.data.fill_(0)` 将偏置初始化为 0。

### 7. 定义损失函数和优化器

```python
loss = nn.MSELoss()
trainer = torch.optim.SGD(net.parameters(), lr=0.03)
```

- `loss = nn.MSELoss()` 定义了均方误差（MSE）作为损失函数，用于评估模型输出与实际标签之间的差异。
- `trainer = torch.optim.SGD(net.parameters(), lr=0.03)` 定义了随机梯度下降（SGD）优化器，学习率为 0.03。

### 8. 训练模型

```python
num_epochs = 3
for epoch in range(num_epochs):
    for X, y in data_iter:
        l = loss(net(X), y)  # 计算损失
        trainer.zero_grad()   # 清零梯度
        l.backward()          # 反向传播计算梯度
        trainer.step()        # 使用梯度更新模型参数
    l = loss(net(features), labels)
    print(f'epoch {epoch + 1}, loss {l:f}')
```

- 训练过程分为 3 个周期（`num_epochs = 3`）。
- 每个周期内，遍历整个训练数据集（按批次处理）。对于每一批数据：
  - `l = loss(net(X), y)` 计算当前批次的损失，`net(X)` 是模型的预测值，`y` 是实际标签。
  - `trainer.zero_grad()` 清除之前的梯度信息（因为 PyTorch 默认会累加梯度）。
  - `l.backward()` 进行反向传播，计算梯度。
  - `trainer.step()` 使用优化器根据梯度更新模型的参数。
- 每个周期结束后，计算并打印整个训练集上的损失。

### 9. 输出估计误差

```python
w = net[0].weight.data
print('w的估计误差：', true_w - w.reshape(true_w.shape))
b = net[0].bias.data
print('b的估计误差：', true_b - b)
```

- 训练完成后，`w` 和 `b` 是模型训练得到的权重和偏置。
- 使用 `true_w` 和 `true_b` 来计算估计误差，即模型预测的权重与偏置与真实值之间的差距。

# 四、SoftMax回归

## 1、从零实现

### 1.1 数学原理

#### 1.1.1 softmax 回归简介

softmax 回归（softmax regression）是**线性模型在多分类问题上的推广**。

对于一个有 $n$ 个类别的分类问题，softmax 回归的目标是：

- **输入**：一个样本的特征向量 $\mathbf{x} \in \mathbb{R}^d$（例如展平后的图像，共784维）
- **输出**：该样本属于每个类别的**概率分布**

#### 1.1.2 线性变换

$$
\mathbf{z} = \mathbf{x}^\top \mathbf{W} + \mathbf{b}\quad \text{(或批量版：} \mathbf{Z} = \mathbf{X} \mathbf{W} + \mathbf{b} \text{)}
$$

其中：

- $\mathbf{W}$ 是 $d \times n$ 的权重矩阵（d是输入特征的数量）
- $\mathbf{b}$ 是 $1 \times n$ 的偏置项
- $\mathbf{x}$ 是 $d \times 1$ 的列向量
- $\mathbf{z}$ 是 $1 \times n$ 的行向量，代表输入样本属于n个类别的得分
- 训练时，$\mathbf{X}$ 为 $批量大小 \times d$ 的矩阵，此时输出为 $批量大小 \times n$，每一行代表的是一个输入样本预测为不同类别的分值
  - $\mathbf{Z}$ 是 $批量大小 \times n$ 的矩阵，一行代表一个样本，每列代表样本预测为某类的得分
  - $\mathbf{W}$ 是 $d \times n$ 的权重矩阵（d是输入特征的数量）

#### 1.1.3 softmax函数

对于一组未归一化的预测分数 $\mathbf{z} = [z_1, z_2, ..., z_n]$，softmax 函数定义为：
$$
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}
$$


- 保证输出是一个概率分布（每个值非负，总和为 1）
- 强化最大的值（因为指数函数增长快）
- 训练时将预测分数矩阵 $\mathbf{z}$ 经过softmax函数转换为概率

#### 1.1.4 模型结构

对于每个输入 $\mathbf{x}$，softmax 回归模型是一个线性变换 + softmax：
$$
\mathbf{z} = \mathbf{x}^\top \mathbf{W} + \mathbf{b} \\ 
\hat{\mathbf{y}} = \text{softmax}(\mathbf{z})
$$
其中：

- $\mathbf{W}$ 是 $d \times n$ 的权重矩阵（d是输入特征的数量）
- $\mathbf{b}$ 是 $1 \times n$ 的偏置项
- 输出 $\hat{\mathbf{y}}$ 是每个类别的预测概率
- 同理，当训练时，输入x为一个批量的矩阵，输出也为一个矩阵，每一行代表这个样本预测为不同类别的概率

#### 1.1.5 损失函数：交叉熵 Cross-Entropy Loss

交叉熵衡量的是模型预测分布与真实标签之间的差异。

设真实标签是 $y$（类别索引），softmax 输出为 $\hat{\mathbf{y}}$，则：
$$
\mathcal{L} = -\log(\hat{y}_y)
$$
如果是批量输入 ${ (\mathbf{x}^{(i)}, y^{(i)}) }_{i=1}^{q}$，则总损失为：
$$
\mathcal{L}_{\text{batch}} = - \frac{1}{q} \sum_{i=1}^{q} \log(\hat{y}^{(i)}_{y^{(i)}})
$$

```python
def accuracy(y_hat, y):  #@save

    return float(cmp.type(y.dtype).sum())
```

- `argmax(axis=1)` 取出每一行中概率最大的索引（即预测类别）

- 比较预测标签与真实标签，统计正确个数

- `if len(y_hat.shape) > 1 and y_hat.shape[1] > 1`判断是否是多分类概率分布

- `cmp = y_hat.type(y.dtype) == y`

  - 将 `y_hat` 转成和 `y` 相同的数据类型（比如 `int64`）

  - 然后用 `==` 判断预测结果和真实标签是否一致

  - 返回一个布尔张量，如 `[True, False, True]`

- `return float(cmp.type(y.dtype).sum())`

  - 将布尔值转成整数（`True` → 1，`False` → 0）
  - 再 `.sum()` 求和，统计正确的数量
  - 最后用 `float()` 转成浮点数

#### 1.2.8 定义实用程序类Accumulator

```python
class Accumulator:  #@save
    """在n个变量上累加"""
    def __init__(self, n):
        self.data = [0.0] * n

    def add(self, *args):
        self.data = [a + float(b) for a, b in zip(self.data, args)]

    def reset(self):
        self.data = [0.0] * len(self.data)

    def __getitem__(self, idx):
        return self.data[idx]
```

这个类 `Accumulator` 是一个很实用的小工具类，它的作用就是：

> ✅ **在多个变量上同时进行累加（统计总和）**，比如：总损失、总正确个数、总样本数等等。

------

我们来一行一行详细解释这个类的功能：

------

✅ `__init__`：初始化

```python
def __init__(self, n):
    self.data = [0.0] * n
```

意思是：

- 创建一个长度为 `n` 的列表 `self.data`
- 每个元素初始值为 `0.0`

👉 比如：`Accumulator(3)` 会初始化为 `[0.0, 0.0, 0.0]`，用于统计三个不同的量。

------

✅ `add(*args)`：累加多个值

```python
def add(self, *args):
    self.data = [a + float(b) for a, b in zip(self.data, args)]
```

- `*args` 表示可以传入多个值（任意个参数）
- `zip(self.data, args)`：把当前的累计值和新传入的值一一配对
- 用列表推导式把每一项都加上去

📌 举个例子：

```python
acc = Accumulator(3)       # 初始： [0.0, 0.0, 0.0]
acc.add(1, 2, 3)            # 加上： [1.0, 2.0, 3.0]
acc.add(4, 0.5, 1.5)        # 加上： [5.0, 2.5, 4.5]
```

------

✅ `reset()`：重置清零

```python
def reset(self):
    self.data = [0.0] * len(self.data)
```

作用：把所有累计值归零。

------

✅ `__getitem__()`：索引访问

```python
def __getitem__(self, idx):
    return self.data[idx]
```

支持用下标直接访问，比如：

```python
acc[0]  # 返回第一个累计值
acc[1]  # 返回第二个
```

------

✅ 举个完整例子：统计损失和准确率

```python
metric = Accumulator(3)  # [损失总和, 正确预测数, 样本数]

# 一次 batch 的训练后：
metric.add(1.2, 8, 10)   # 表示：损失1.2，预测对了8个，总共10个样本

# 再一次 batch：
metric.add(1.0, 7, 10)

# 当前累计值：
print(metric[0])  # 总损失 = 2.2
print(metric[1])  # 总正确 = 15
print(metric[2])  # 总样本 = 20
```

------

✅ 总结一句话：

`Accumulator(n)` 是个**可以同时累加 n 个指标的小工具类**，用于统计训练过程中的各种指标，非常适合训练循环中使用。

#### 1.2.9 单轮训练函数

```python
def train_epoch_ch3(net, train_iter, loss, updater):  #@save
    """训练模型一个迭代周期（定义见第3章）"""
    # 将模型设置为训练模式
    if isinstance(net, torch.nn.Module):
        net.train()
    # 训练损失总和、训练准确度总和、样本数
    metric = Accumulator(3)
    for X, y in train_iter:
        # 计算梯度并更新参数
        y_hat = net(X)
        l = loss(y_hat, y)
        if isinstance(updater, torch.optim.Optimizer):
            # 使用PyTorch内置的优化器和损失函数
            updater.zero_grad()
            l.mean().backward()
            updater.step()
        else:
            # 使用定制的优化器和损失函数
            l.sum().backward()
            updater(X.shape[0])
        metric.add(float(l.sum()), accuracy(y_hat, y), y.numel())
    # 返回训练损失和训练精度
    return metric[0] / metric[2], metric[1] / metric[2]
```

`train_epoch_ch3` 是训练过程中的一个**核心函数**，它负责：

> ✅ **执行一个训练周期（epoch）中所有 mini-batch 的前向传播、反向传播、参数更新，并统计训练损失和准确率。**

我们来**逐行拆解讲解**👇

------


- `net`: 你的模型
- `train_iter`: 数据加载器（每次返回一个 mini-batch）
- `loss`: 损失函数（如交叉熵）
- `updater`: 优化器（SGD 或手写）

------

✅ 1. 设置为训练模式

```python
if isinstance(net, torch.nn.Module):
    net.train()
```

- `.train()` 让模型进入训练模式（例如启用 dropout、batch norm 等行为）
- 如果用的是 PyTorch 模型结构就执行

------

✅ 2. 初始化统计器

```python
metric = Accumulator(3)
```

这个 `metric` 会记录三个东西：

| metric[i] | 含义                       |
| --------- | -------------------------- |
| `0`       | 累计损失（loss sum）       |
| `1`       | 累计预测正确数量           |
| `2`       | 样本总数（num of samples） |

------

✅ 3. 遍历一个 epoch 的所有 mini-batch

```python
for X, y in train_iter:
```

- `X`: 一批样本（比如 shape 是 `(256, 1, 28, 28)`）
- `y`: 对应的真实标签（shape 是 `(256,)`）

------

✅ 4. 前向传播 & 损失计算

```python
y_hat = net(X)           # 模型预测
l = loss(y_hat, y)       # 计算损失
l` 是一个包含每个样本损失的张量，比如 `(256,)
```

------

✅ 5. 判断优化器类型（是否是 PyTorch 的 Optimizer）

```python
if isinstance(updater, torch.optim.Optimizer):
```

分两种情况处理：

------

🧠 情况 1：使用 PyTorch 内置优化器

```python
updater.zero_grad()      # 清空旧梯度
l.mean().backward()      # 反向传播（用平均损失）
updater.step()           # 更新参数
```

- `l.mean()` 是用平均损失反向传播
- `.step()` 是 PyTorch 的标准更新方式

------

🧠 情况 2：使用自定义优化器（比如手写的 SGD）

```python
l.sum().backward()        # 反向传播（用总损失）
updater(X.shape[0])       # 你自己定义的 updater 函数，接收 batch size
```

如果自己定义的updater函数不接收batch_size参数，也就是参数更新函数不除批量大小，那么反向传播的时候要用平均损失，即`l.mean().backward()`

------

✅ 6. 累加训练指标

```python
metric.add(float(l.sum()), accuracy(y_hat, y), y.numel())
```

分别加：

- `float(l.sum())`: 当前 batch 的总损失
- `accuracy(...)`: 当前 batch 预测对的样本数
- `y.numel()`: 当前 batch 样本总数

------

✅ 7. 返回平均损失和平均准确率

```python
return metric[0] / metric[2], metric[1] / metric[2]
```

即：

```python
avg_loss = 总损失 / 样本数
avg_acc = 正确预测数 / 样本数
```

------

✅ 举个例子

假设两个 batch：

| batch | loss.sum() | correct | total |
| ----- | ---------- | ------- | ----- |
| 1     | 32.0       | 180     | 256   |
| 2     | 30.0       | 170     | 256   |

那么：

```python
metric = [62.0, 350, 512]
avg_loss = 62 / 512 ≈ 0.121
avg_acc  = 350 / 512 ≈ 0.684
```

✅ 总结一句话：

这个函数就是你训练模型的「一次大循环」，它每次跑完整个训练集（一个 epoch），返回：

> 📌 **本轮平均损失 + 平均准确率**

```python
    """在动画中绘制数据"""
    def __init__(self, xlabel=None, ylabel=None, legend=None, xlim=None,
                 ylim=None, xscale='linear', yscale='linear',
                 fmts=('-', 'm--', 'g-.', 'r:'), nrows=1, ncols=1,
                 figsize=(3.5, 2.5)):
        # 增量地绘制多条线
        if legend is None:
            legend = []
        d2l.use_svg_display()
        self.fig, self.axes = d2l.plt.subplots(nrows, ncols, figsize=figsize)
        if nrows * ncols == 1:

        # 使用lambda函数捕获参数

        self.X, self.Y, self.fmts = None, None, fmts

    def add(self, x, y):
        # 向图表中添加多个数据点
        if not hasattr(y, "__len__"):
            y = [y]
        n = len(y)
        if not hasattr(x, "__len__"):
            x = [x] * n
        if not self.X:

                self.Y[i].append(b)
        self.axes[0].cla()
        for x, y, fmt in zip(self.X, self.Y, self.fmts):

        self.config_axes()
        display.display(self.fig)
        display.clear_output(wait=True)
```

### 1.3 模型优化

#### 1.3.1 交叉熵损失的问题及解决方案

🚨  **log(0)** 或 log(接近 0) → 无穷大 / NaN

- 如果模型预测中某个类别的概率是 **0 或接近 0**，而这个类别恰好是正确答案，那么就会出现：
  $$
  -\log(0) = +\infty
  $$
  
- 在 PyTorch 中，如果你直接 `torch.log(y_hat)` 而没有做安全处理，就有可能爆炸。

✅ **解决方法**：

- 给 `y_hat` 加一个非常小的常数：

  ```python
  torch.log(y_hat + 1e-9)
  ```

- 或者使用 PyTorch 提供的安全函数：

  ```python
  F.cross_entropy(logits, targets)  # 内部做了log_softmax + one_hot
  ```

✅ 举个你自己的代码例子：

你原来的交叉熵函数是这样的：

```python
def cross_entropy(y_hat, y):
    return -torch.log(y_hat[range(len(y_hat)), y])
```

------

✅ 加上 epsilon 的写法如下：

```python
def cross_entropy_safe(y_hat, y, eps=1e-9):
    # 防止 log(0) 导致 NaN
    clipped_y_hat = y_hat.clamp(min=eps)
    return -torch.log(clipped_y_hat[range(len(y),), y])
```

------

📌 说明：

- `y_hat.clamp(min=eps)`：将 `y_hat` 中所有小于 `eps` 的值替换成 `eps`（如 1e-9）
  - 这样即使某类的预测概率为 0，实际值也变成了 `1e-9`，不会出现 `log(0)`
- `eps=1e-9` 是常见的安全阈值，你也可以调得更小或更大

------

🔁 示例对比：

```python
y_hat = torch.tensor([[1e-10, 0.999999999, 0.0]])
y = torch.tensor([2])
```

如果你用原版的 `cross_entropy`，会爆炸：

```python
- torch.log(y_hat[0, 2])  # log(0) → -inf
```

使用安全版本：

```python
loss = cross_entropy_safe(y_hat, y)
print(loss)  # 合理数值（不会是 nan 或 inf）
```

------

✅ 推荐实践建议：

- 如果你手动实现 softmax + cross_entropy，**一定要加 epsilon**。
- 如果你用的是 `torch.nn.CrossEntropyLoss()`，就 **不用加 epsilon**，因为它内部已经做了防护。

#### 1.3.2 数值不稳定：softmax + log 可能导致 underflow**

- softmax 中用了指数函数 `exp()`，对数值波动很敏感。
- 如果 logits（模型未归一化的输出）过大或过小，就可能导致：
  - `exp(x)` 爆炸成 `inf`
  - 或 `log(exp(x))` 精度下降，最终 loss 不稳定

✅ **解决方法**：

- 使用 `log-sum-exp` 技巧，或用内置函数：

  ```python
  torch.nn.CrossEntropyLoss()
  ```

  它内部自动结合了 softmax 和 log，数值更稳定。

🧠 **1️⃣ 什么是 log-sum-exp（LSE）**

log-sum-exp 是下面这个表达式的名字：
$$
\boxed{ \log \left( \sum_{i=1}^n e^{z_i} \right) }
$$
这个看似简单的式子，在 softmax、交叉熵、变分推断、最大似然估计等地方都非常常见。

------

🔥 **2️⃣ log-sum-exp 为什么容易出问题（数值不稳定）**

当 $z_i$ 中某些值非常大（比如 > 100），你会遇到：

```python
e^{z_i} → inf （爆炸）
```

最终：

- `sum(exp(z)) → inf`
- `log(inf) → inf`
- → 出现 `nan`、`inf`

📉 比如：

```python
z = torch.tensor([1000.0, 1001.0, 1002.0])
torch.sum(torch.exp(z))  → 会变成 inf
torch.log(torch.sum(torch.exp(z))) → nan
```

------

 ✅ **3️⃣ log-sum-exp 技巧（数值稳定处理）**

我们做一个**数学变换**，减去最大值 $a$：
$$
\log \sum_i e^{z_i} = \log \left( e^a \sum_i e^{z_i - a} \right) = a + \log \sum_i e^{z_i - a}\\\\
其中：
a = \max_i z_i
$$


------

🧠 为什么这个式子等价？

因为：

- $e^{z_i} = e^{(z_i - a)} \cdot e^a$
- 所以 $e^{z_i}$ 的总和就可以提出 $e^a$
- 再用 log 展开：$\log(ab) = \log a + \log b$

------

✅ 这有什么好处？

如果 $z_i$ 很大，比如 1000：

- 那么 $z_i - \max(z)$ 就会变成：
  - `[-2, -1, 0]`（最大值变成 0，其它是负数）
- 所以 $\exp(z_i - \max(z))$ 都会是非常 **小的正数**，不会爆炸！
- **整个求和过程就安全了**

------

🔧 **4️⃣ PyTorch 手动实现 log-sum-exp**

```python
def log_sum_exp(z, dim=1):
    z_max = z.max(dim=dim, keepdim=True)[0]
    return z_max + torch.log(torch.sum(torch.exp(z - z_max), dim=dim, keepdim=True))
```

------

🔍 **5️⃣ 和 softmax / log-softmax 有什么关系？**

**softmax：**
$$
\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$
**log-softmax：**
$$
\log(\text{softmax}(z_i)) = z_i - \log \sum_j e^{z_j}
$$
**log-sum-exp：**
$$
\log \sum_i e^{z_i} = \log \left( e^a \sum_i e^{z_i - a} \right) = a + \log \sum_i e^{z_i - a}\\\\
其中：
a = \max_i z_i
$$
你看到了没？

> ✅ log-softmax 就是 `z_i - logsumexp(z)`！

------

📈 **6️⃣ 直观图理解（假想图解）**

```matlab
原始 z 向量： [1000, 1001, 1002]
exp(z):       [inf,   inf,   inf]  ❌ 数值爆炸

处理后：
z - max(z) = [-2, -1, 0]
exp(z - max): [0.135, 0.367, 1.0] ✅ 安全

sum(exp): 约 1.5
log(sum): ~0.41
logsumexp: 1002 + 0.41 = 1002.41 ✅
```

**7️⃣ 修改源代码优化**

🧩 原来的代码是这样的：

```python
def cross_entropy(y_hat, y):
    return - torch.log(y_hat[range(len(y_hat)), y])
```

这个版本假设 `y_hat` 是已经经过 softmax 的概率分布，但这样容易出问题（log(0)、数值不稳定），所以我们建议你传入原始的 `logits`，使用 log-sum-exp 技巧手动算。

------

✅ 改写为 log-sum-exp 稳定版本

✅ 输入是 logits（还没经过 softmax），直接使用 log-sum-exp 技巧：

```python
def cross_entropy_logsumexp(logits, y):
    # logits: shape (batch_size, num_classes)
    # y: shape (batch_size,)

    # Step 1: 取每行最大值（用于稳定）
    # logits.max返回一个元组，第一个元素是最大值，第二个元素是最大值对应的索引
    max_logits = logits.max(dim=1, keepdim=True)[0]  # shape: (batch_size, 1)

    # Step 2: log-sum-exp
    log_sum_exp = max_logits + torch.log(torch.sum(torch.exp(logits - max_logits), dim=1, keepdim=True))  # shape: (batch_size, 1)

    # Step 3: 正确类的 logit（未 softmax）
    z_y = logits[range(len(y)), y].unsqueeze(1)  # shape: (batch_size, 1)

    # Step 4: Cross-Entropy = log-sum-exp - z_y
    loss = log_sum_exp - z_y

    return loss.squeeze(1)  # shape: (batch_size,) 与原来保持一致
```

------

💡 加上 `.mean()` 或 `.sum()` 得到标量 loss：

```python
loss = cross_entropy_logsumexp(logits, y).mean()
```

# 五、感知机

## 1、感知机

### 1.1 感知机原理

**🌟 感知机是什么？**

感知机（**Perceptron**）是最早的**人工神经网络模型**之一，用来**进行二分类任务**。它模仿生物神经元的激活机制，来判断一个输入是属于“正类”还是“负类”。

你可以把它想象成一个“**超平面**”来分隔两类数据。

------

**🔧 感知机模型结构**

感知机其实非常简单，本质上就是一个**线性模型**加一个**符号函数**：
$$
\hat{y} = \text{sign}( \mathbf{w}^\top \mathbf{x} + b )
$$
其中：

- $\mathbf{x} = (x_1, x_2, ..., x_n)$：输入特征（n维向量）
- $\mathbf{w} = (w_1, w_2, ..., w_n)$：权重向量
- $b$：偏置项
- $\text{sign}(\cdot)$：符号函数，结果为 +1 或 −1

------

**🧠 它怎么分类？**

你可以把 $\mathbf{w}^\top \mathbf{x} + b = 0$ 理解为一个“决策边界”：

- 当 $\mathbf{w}^\top \mathbf{x} + b > 0$，预测为 +1 类
- 当 $\mathbf{w}^\top \mathbf{x} + b < 0$，预测为 -1 类

------

**📘 感知机学习算法**

训练目标：**找到一组 $\mathbf{w}$,b，使得所有样本都能被正确分类。**

如果某个样本被分类错了，比如它应该是 +1 但模型预测是 -1，我们就“惩罚”模型、调整参数！

**📌 更新规则：**

对于训练集中每一个被错分的样本 $(\mathbf{x}_i, y_i)$，更新：
$$
\mathbf{w} := \mathbf{w} + \eta \cdot y_i \cdot \mathbf{x}_i\\
b := b + \eta \cdot y_i
$$
其中 $\eta$ 是学习率（一般是个很小的正数，比如 0.1）。

这个规则其实很简单：

- 如果样本是正类但被分成负类，就把 $\mathbf{w}$ 往 $\mathbf{x}_i$ 的方向推；

- 如果样本是负类但被分成正类，就把 $\mathbf{w}$ 往反方向推。

- 这一步控制了权重的“推向”：

  ✅ 情况 1：样本是 **正类**（$y_i = +1$），但模型错分成了负类

  - 更新公式变成：
    $$
    \mathbf{w} := \mathbf{w} + \eta \cdot (+1) \cdot \mathbf{x}_i = \mathbf{w} + \eta \cdot \mathbf{x}_i
    $$
  
- 含义：**把权重向输入样本的方向拉一拉**
  
- 目的：下次再遇到类似样本时，$\mathbf{w}^\top \mathbf{x}_i$ 就更大，能变成正类
  
------

**❌ 情况 2：样本是 负类（$y_i = -1$），但被预测成正类**

- 更新公式变成：
    $$
    \mathbf{w} := \mathbf{w} + \eta \cdot (-1) \cdot \mathbf{x}_i = \mathbf{w} - \eta \cdot \mathbf{x}_i
    $$
    
  - 含义：**把权重往输入的反方向推一下**

  - 目的：下次遇到类似的负样本，让 $\mathbf{w}^\top \mathbf{x}_i$ 变小，变成负数，从而正确分类

  ------

  **📌 举个超简单的例子！**

  假设：

  - 你有一个二维样本 $\mathbf{x}_i = (2, 1)$
- 你当前的权重是 $\mathbf{w} = (1, 1)$
  - 偏置暂时不管
  - 学习率 $\eta = 1$
  
  现在：

  - 如果它是正类（$y=+1$），但你模型却判成了负类，就更新：

    $\mathbf{w} = (1, 1) + 1 \cdot 1 \cdot (2, 1) = (3, 2)$

    权重“朝着样本方向”被拉了过去！

  - 如果它是负类（$y=-1$），但你判成了正类，就更新：

    $\mathbf{w} = (1, 1) + 1 \cdot (-1) \cdot (2, 1) = (-1, 0)$

    权重“往反方向”被推开！

  ------

  **🎯 总结一句话：**

  > 错了就推！推哪边看类别！
> 推的方向就是：**正类→拉近，负类→拉远**。

**当标签采用01时，用以下方法更新**

**感知机的训练过程：**

- **误差计算**：计算预测值和真实标签之间的差距。

  $\text{误差} = y_{\text{true}} - \hat{y}$

- **更新规则**：根据误差调整权重和偏差。

  $w_i \leftarrow w_i + \eta \cdot \text{误差} \cdot x_i$

  $b \leftarrow b + \eta \cdot \text{误差}$

  其中，$\eta$ 是学习率。

**🧮 损失函数（可以选）**

也可以写成感知机的损失函数（只对错分样本有惩罚）：
$$
L(\mathbf{w}, b) = - \sum_{\text{错分样本}} y_i(\mathbf{w}^\top \mathbf{x}_i + b)
$$


------

**📈 感知机能做什么？**

- 可以对**线性可分数据集**进行分类；
- 它的分类边界是一个**超平面**；
- 如果数据是线性不可分的，感知机就无法收敛（除非做核技巧等扩展）。

------

**📊 举个图示例子**

比如我们要分类苹果（+1）和梨（-1），特征是重量和颜色深浅：

- 用感知机学出来的模型，其实就是在二维平面上画一条线：
  - 线的一边是苹果；
  - 另一边是梨；
  - 然后不断修线的位置直到能把训练数据分开。

------

**✅ 总结一句话**

> 感知机就是一个“**能自动调整自己画的线，把两类数据分开**”的简单神经元模型！

## 2、多层感知机

**多层感知机（MLP）详解**

多层感知机（MLP，Multilayer Perceptron）是一种前馈神经网络，它由多个层（输入层、隐藏层、输出层）组成。MLP 是一种用于解决回归和分类问题的强大工具，尤其是在深度学习框架下广泛应用。

### 2.1. 网络结构

**2.1.1 输入层（Input Layer）**

- **功能**：接受外部输入数据。
- **节点数**：等于输入特征的维度。
- 例如，对于一个28x28像素的图像，输入层会有784个神经元（28 * 28）。

**2.1.2 隐藏层（Hidden Layer）**

- **功能**：对输入数据进行非线性转换，学习输入特征的高级表示。
- **节点数**：隐藏层神经元的数量是超参数，通常通过实验选择。隐藏层数量和每层的神经元数目对模型的性能有重要影响。
- **激活函数**：常用的激活函数包括ReLU、Sigmoid、Tanh等。

**2.1.3 输出层（Output Layer）**

- **功能**：根据任务的需求，输出最终结果。
- **节点数**：通常与任务的类别数相同。例如，在二分类问题中，输出层有1个节点；在多分类问题中，输出层的节点数等于类别数。
- **激活函数**：对于回归问题，输出层通常不使用激活函数；对于分类问题，通常使用 **Softmax**（多分类）或 **Sigmoid**（二分类）。

### 2.2. 前向传播

前向传播过程是将输入数据通过网络层层传递，直到输出层产生结果。

1. **输入层到隐藏层**：

   - 输入数据经过加权求和后，使用激活函数进行非线性变换：
     $$
     h = f(W \cdot x + b)
     $$
     其中，\(W\) 是权重矩阵，\(x\) 是输入数据，\(b\) 是偏置项，\(f\) 是激活函数（如ReLU）。

2. **隐藏层到输出层**：

   - 隐藏层的输出经过加权求和，并最终得到输出：
     $$
     y = \text{softmax}(W' \cdot h + b')
     $$

     其中，\(W'\) 是隐藏层到输出层的权重矩阵，\(b'\) 是输出层的偏置项。

### 2.3. 激活函数

激活函数引入了非线性，使得网络能够学习复杂的模式。常见的激活函数有：

**2.3.1 ReLU（Rectified Linear Unit）**

- **公式**：$ f(x) = \max(0, x) $
- **优点**：计算简单，收敛速度快，避免了Sigmoid和Tanh的梯度消失问题。
- **缺点**：可能导致“死亡神经元”（神经元的输出一直为0）。

**2.3.2 Sigmoid**

- **公式**：
  $$
  f(x) = \frac{1}{1 + e^{-x}} 
  $$
  
- **优点**：输出范围在(0, 1)之间，适用于二分类问题。

- **缺点**：容易导致梯度消失，尤其是当输入值很大或很小时。

**2.3.3 Tanh**

- **公式**：
  $$
  f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}
  $$
  
- **优点**：输出范围在(-1, 1)之间，效果比Sigmoid稍好。

- **缺点**：同样存在梯度消失问题。

**2.3.4 Softmax**

- **公式**：
  $$
  p_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}
  $$
  
- **用途**：常用于多分类问题的输出层，将每个类的预测结果转换为概率。

### 2.4. 损失函数

**2.4.1 交叉熵损失（Cross-Entropy Loss）**

- **用途**：用于分类问题，特别是多分类问题。它度量了模型的预测概率分布与真实标签之间的差异。

- **公式**：
  $$
  L = - \sum_{i=1}^{C} y_i \log(p_i)
  $$

  其中，\(y_i\) 是目标标签的one-hot编码，\(p_i\) 是模型输出的概率。

**2.4.2 均方误差（Mean Squared Error, MSE）**

- **用途**：通常用于回归问题，度量预测值与真实值之间的差异。

- **公式**：
  $$
  L = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
  $$
  其中，$y_i$ 是真实值，$\hat{y}_i$ 是预测值。

### 2.5. 反向传播与梯度下降

**2.5.1 反向传播（Backpropagation）**

- 反向传播算法通过链式法则计算损失函数相对于每个权重的梯度。
- 在每一层的神经元上计算梯度，并将误差逐层反向传递，更新每个参数。

**2.5.2 梯度下降（Gradient Descent）**

- 反向传播计算完梯度后，通过梯度下降算法更新权重：
  $$
  W = W - \eta \frac{\partial L}{\partial W}
  $$
  其中，$\eta$ 是学习率，$\frac{\partial L}{\partial W}$ 是损失函数相对于权重的梯度。

- 反向传播计算完梯度后，通过梯度下降算法更新偏差：

$$
b = b - \eta \frac{\partial L}{\partial b}
$$



### 2.6. 示例：简单的多层感知机（MLP）

```python
import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import DataLoader, TensorDataset
import numpy as np
import matplotlib.pyplot as plt

# 1. 数据准备
# 这里我们使用随机数据来模拟训练数据
# 假设输入是二维特征，输出是二分类结果（0 或 1）

# 随机生成1000个数据点
np.random.seed(0)
torch.manual_seed(0)

X = np.random.rand(1000, 2)  # 1000个样本，2个特征
y = (X[:, 0] + X[:, 1] > 1).astype(int)  # 分类标签：如果两个特征之和大于1，标签为1，否则为0

# 将数据转换为 Tensor
X_tensor = torch.tensor(X, dtype=torch.float32)
y_tensor = torch.tensor(y, dtype=torch.long)

# 创建数据集
dataset = TensorDataset(X_tensor, y_tensor)
train_loader = DataLoader(dataset, batch_size=32, shuffle=True)

# 2. 定义 MLP 模型
class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(MLP, self).__init__()
        # 定义模型层
        self.fc1 = nn.Linear(input_dim, hidden_dim)  # 第一层：输入层到隐含层
        self.relu = nn.ReLU()  # 激活函数
        self.fc2 = nn.Linear(hidden_dim, output_dim)  # 第二层：隐含层到输出层

    def forward(self, x):
        x = self.fc1(x)  # 输入到第一层
        x = self.relu(x)  # 激活函数
        x = self.fc2(x)  # 输入到第二层
        return x

# 3. 实例化模型
input_dim = 2  # 输入特征数量
hidden_dim = 5  # 隐含层神经元数量
output_dim = 2  # 输出类别数量（0或1）

model = MLP(input_dim, hidden_dim, output_dim)

# 4. 定义损失函数和优化器
criterion = nn.CrossEntropyLoss()  # 使用交叉熵损失函数进行分类
optimizer = optim.SGD(model.parameters(), lr=0.1)  # 使用随机梯度下降优化器

# 5. 训练模型
epochs = 1000
losses = []

for epoch in range(epochs):
    for X_batch, y_batch in train_loader:
        # 1. 前向传播
        output = model(X_batch)
        loss = criterion(output, y_batch)  # 计算损失
        
        # 2. 反向传播
        optimizer.zero_grad()  # 清空梯度
        loss.backward()  # 计算梯度
        optimizer.step()  # 更新参数

    # 保存每个 epoch 的损失值
    losses.append(loss.item())
    
    # 打印每50个 epoch 的损失
    if epoch % 50 == 0:
        print(f"Epoch [{epoch}/{epochs}], Loss: {loss.item():.4f}")

# 6. 绘制损失图
plt.plot(losses)
plt.xlabel('Epochs')
plt.ylabel('Loss')
plt.title('Training Loss')
plt.show()

# 7. 模型评估
with torch.no_grad():  # 不需要计算梯度
    test_input = torch.tensor([[0.5, 0.5], [0.2, 0.8]], dtype=torch.float32)  # 测试数据
    test_output = model(test_input)
    _, predicted = torch.max(test_output, 1)  # 获取预测的类别
    print(f"Predictions: {predicted.numpy()}")
```

✅ **Xavier 初始化（自定义参数初始化）**

**Xavier 初始化**（也称为 **Glorot 初始化**）是一种神经网络参数的初始化方法，它旨在解决深度神经网络训练中的梯度消失和梯度爆炸问题。

**Xavier 初始化公式：**

- 对于一个使用 `sigmoid` 或 `tanh` 激活函数的神经网络，**Xavier 初始化**会将每层的权重矩阵初始化为从均匀分布或正态分布中抽取的随机值，初始化的标准差为：

  - **均匀分布**：
     权重从均匀分布中抽取，范围是 $[- \sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}} , \sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}} ]$，其中 $n_{\text{in}}$​ 是输入节点的数量，$n_{\text{out}}$​ 是输出节点的数量。
  - **正态分布**：
     权重从均值为 0，方差为 $\frac{2}{n_{\text{in}} + n_{\text{out}}}$​ 的正态分布中抽取。

  其中，`n_in` 是前一层的神经元数目，`n_out` 是当前层的神经元数目。

**在 PyTorch 中如何使用 Xavier 初始化？**

PyTorch 提供了 `torch.nn.init` 模块来支持 Xavier 初始化。你可以通过 `torch.nn.init.xavier_uniform_` 或 `torch.nn.init.xavier_normal_` 来实现。

- `xavier_uniform_`：从均匀分布中初始化权重。
- `xavier_normal_`：从正态分布中初始化权重。

**示例：**

```python
import torch
import torch.nn as nn
import torch.nn.init as init

class MLP(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(MLP, self).__init__()
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, output_dim)
        
        # 使用 Xavier 初始化
        init.xavier_uniform_(self.fc1.weight)  # 使用均匀分布的 Xavier 初始化
        init.zeros_(self.fc1.bias)             # 偏置初始化为 0
        init.xavier_uniform_(self.fc2.weight)  # 使用均匀分布的 Xavier 初始化
        init.zeros_(self.fc2.bias)             # 偏置初始化为 0
    
    def forward(self, x):
        x = self.fc1(x)
        x = torch.relu(x)  # 使用 ReLU 激活函数
        x = self.fc2(x)
        return x
```

在这个例子中：

- 我们使用 `xavier_uniform_` 对 `fc1` 和 `fc2` 的权重进行初始化，保证它们遵循 Xavier 初始化方法。
- 偏置项被初始化为零。

**Xavier 初始化适用的激活函数：**

Xavier 初始化特别适用于 **Sigmoid** 和 **Tanh** 激活函数。因为这些激活函数的输出范围是有限的（Sigmoid: [0, 1]，Tanh: [-1, 1]），通过这种初始化方法可以避免输出值过大或过小的问题，保证梯度的稳定性。

# 六、模型选择 + 过拟合和欠拟合

## 1、模型选择

### 1.1 数据集

在机器学习和深度学习中，数据集通常被分为三个部分：**训练数据集**、**验证数据集**（Validation Dataset）和**测试数据集**（Test Dataset）。每个数据集在模型的训练和评估过程中都有不同的作用。具体来说，**验证数据集**和**测试数据集**的作用如下：

通常使用test_data，其实是验证数据集，测试数据集往往是另外新的数据，可能都不知道标签

1. **训练数据集（Training Dataset）**

- **用途**：用于训练模型，更新模型的参数（如权重和偏置）。通过不断训练，模型会通过最小化损失函数来学习数据中的规律。
- **特点**：模型在这个数据集上进行训练，并逐渐调整内部参数以便更好地拟合数据。

2. **验证数据集（Validation Dataset）**

- **用途**：用于评估模型在训练过程中的表现，帮助调整模型的超参数（如学习率、网络结构、正则化等）。
- **特点**：验证数据集不会直接参与模型的训练，因此它不影响模型的学习过程，但它会帮助你选择最佳的模型配置。验证集可以帮助你检查模型是否出现了**过拟合**（Overfitting），即模型过度拟合训练数据而对新数据的泛化能力较差。
- **作用**：
  - **超参数调整**：根据验证集的表现来调整模型的超参数。
  - **避免过拟合**：在训练过程中，模型可能会在训练集上表现得很好，但在新数据上表现不佳（即过拟合）。通过验证集，可以定期检查模型的性能，避免过拟合现象。
  - **模型选择**：如果你训练了多个不同的模型，可以使用验证集来选择性能最好的模型。

3. **测试数据集（Test Dataset）**

- **用途**：用于评估模型的最终性能。测试集是完全独立的，应该在训练和验证过程中保持未见过的数据状态。只有在模型训练完毕且确定最终配置时，才使用测试集进行评估。
- **特点**：测试数据集的目的是模拟模型在真实世界中的表现，检验其泛化能力。测试集不能用于训练和调参。
- **作用**：
  - **最终评估**：测试集用于衡量模型的最终表现，通常是用来报告模型的准确率、召回率、F1 分数等评估指标。
  - **模拟现实应用**：它表示模型在面对新数据（即模型未曾见过的数据）时的表现。

### 1.2 K折交叉验证

**K折交叉验证（K-Fold Cross Validation）**是一种评估机器学习模型泛化能力的常用技术。它通过将数据集划分为K个子集（folds），并进行K次训练和验证，确保每个数据点都能作为训练数据和测试数据的一部分，从而得到更稳健和可靠的评估结果。K折交叉验证的主要目的是评估模型在不同数据分布上的表现，减少模型选择中的偶然性，防止过拟合。

1️⃣ **K折交叉验证的工作流程：**

假设数据集的大小为 NNN，选择的折数为 KKK，以下是 K折交叉验证的基本步骤：

1. **数据分割**：将数据集随机划分成K个大小相等的子集（folds）。每个子集的数据点应该尽量均匀分布，确保每个fold包含的数据分布相似。
2. **模型训练与验证**：
   - 在每一轮交叉验证中，选择一个fold作为**验证集**，其余的K−1K-1K−1个fold作为**训练集**。
   - 使用训练集训练模型，并在验证集上评估模型性能。
3. **重复K次**：重复步骤2 K次，每次选择不同的子集作为验证集，直到每个fold都至少被用作一次验证集。
4. **结果汇总**：
   - 计算模型在K次验证中各次的表现（如准确率、均方误差等）。
   - 最终的评估结果通常是这些K次结果的平均值，用于衡量模型的整体表现。

2️⃣ **示例：**

假设我们有一个包含1000个数据点的数据集，选择K=5进行交叉验证。数据集将被划分为5个fold，每个fold包含200个数据点。

- **第1轮**：使用第1、2、3、4个fold进行训练，第5个fold进行验证。
- **第2轮**：使用第2、3、4、5个fold进行训练，第1个fold进行验证。
- **第3轮**：使用第1、3、4、5个fold进行训练，第2个fold进行验证。
- **第4轮**：使用第1、2、4、5个fold进行训练，第3个fold进行验证。
- **第5轮**：使用第1、2、3、5个fold进行训练，第4个fold进行验证。

最后，计算每一轮交叉验证的评估指标（如准确率），并求出它们的平均值作为模型的最终评估结果。

3️⃣ **K折交叉验证的优点：**

1. **更稳定的评估**：通过多次使用不同的数据子集进行训练和验证，可以减少模型评估的方差，避免由于某个特定数据集划分的偶然性造成的误差。
2. **充分利用数据**：所有数据点都会被用作训练集和验证集，因此不会浪费数据。
3. **防止过拟合**：通过验证模型在不同数据子集上的表现，可以较好地评估模型的泛化能力，从而避免过拟合。

4️⃣ **K折交叉验证的缺点：**

1. **计算成本高**：由于需要进行K次模型训练和验证，因此K折交叉验证的计算开销较大，尤其是当数据集非常大或者模型训练时间很长时。
2. **可能不适合小数据集**：如果数据集较小，K折交叉验证可能会导致较大的方差，尤其是在K值较大时。此时，可能需要采用其他方法（如留一交叉验证）。

### 1.3 过拟合和欠拟合

**过拟合（Overfitting）**和**欠拟合（Underfitting）**是机器学习中常见的两个问题，它们分别描述了模型在训练过程中与数据集之间的适应程度。下面详细解释这两个概念：

![underfit_overfit_1](.\resources\underfit_overfit_1.png)

#### 1.3.1 过拟合（Overfitting）

过拟合是指模型在训练数据上表现得非常好，但在新数据（如测试集或验证集）上表现较差的情况。换句话说，过拟合的模型**过度地适应了训练数据的细节和噪声**，导致其泛化能力很差。

**1️⃣ 过拟合的特征：**

- **高训练准确率，低测试准确率**：模型在训练集上非常准确，但在测试集上表现不佳。
- **模型复杂度过高**：模型的复杂度过高，例如参数过多，或者网络结构过于复杂，导致模型能够捕捉到训练数据中的噪声和不规则性，而不是仅仅学习数据的基本模式。
- **对噪声的敏感性**：模型过分依赖训练集中的偶然性或噪声，忽视了数据的真正规律。

2️⃣ **过拟合的原因：**

- **模型过于复杂**：例如，使用了一个非常复杂的神经网络，导致模型学习了训练数据中的所有细节。
- **训练数据量不足**：当训练数据较少时，模型很容易记住所有训练样本的特征，而无法从中总结出通用的规律。
- **训练时间过长**：训练过久，模型可能开始记住训练数据中的噪声和特定细节，而不再学习数据的基本规律。

3️⃣ **如何避免过拟合：**

- **简化模型**：减少模型的复杂度，例如减少神经网络层数或每层的神经元数量，或者使用更简单的模型（例如线性回归、决策树等）。
- **增加训练数据**：增加更多的训练样本，帮助模型更好地学习数据的真实模式。
- **正则化**：使用L1、L2正则化（例如Ridge、Lasso）来限制模型的复杂度，或者使用Dropout等技术，防止模型过分依赖某些特征。
- **使用交叉验证**：通过交叉验证来监控模型在不同数据集上的表现，避免过度拟合某个特定的训练集。

#### 1.3.2. 欠拟合（Underfitting）

欠拟合是指模型无法在训练数据上有效地学习规律，表现出较差的训练效果，并且在测试数据上也很差。换句话说，欠拟合的模型**没有充分地学习到训练数据的特征**，通常是因为模型太简单，或者训练不充分。

1️⃣ **欠拟合的特征：**

- **高训练误差和高测试误差**：模型在训练集和测试集上都表现较差，无法准确地捕捉数据中的关系。
- **模型复杂度过低**：模型太简单，无法捕捉数据的复杂性。比如使用了过于简单的线性模型来拟合高度非线性的关系。
- **训练不足**：模型训练的轮数太少，未能充分学习数据的规律。

**2️⃣ 欠拟合的原因：**

- **模型过于简单**：例如，使用线性模型拟合非线性的数据，或者没有足够的特征来描述数据的复杂性。
- **特征不足**：数据中可能有潜在的重要特征没有被引入模型。
- **训练时间过短**：训练的次数太少，导致模型未能充分学习数据中的规律。

3️⃣ **如何避免欠拟合：**

- **增加模型复杂度**：使用更复杂的模型（例如，增加更多的神经网络层数，或者选择更复杂的模型如深度神经网络、决策树等）。
- **增加特征**：通过特征工程，增加更多能够反映数据内在规律的特征。
- **延长训练时间**：增加训练轮数，允许模型有更多的时间去学习数据中的规律。

**总结：**

- **过拟合**：模型对训练数据学习过度，能够完美拟合训练数据，但泛化能力差，在新数据上表现不佳。通常由于模型过于复杂或训练数据过少。
- **欠拟合**：模型无法从训练数据中学习到足够的规律，表现出较差的性能，通常是由于模型过于简单或训练不足。

#### 1.3.3 模型容量

**模型容量（Model Capacity）\**是指一个模型能够学习和拟合数据的能力，也可以理解为模型的\**表示能力**。模型容量与模型的复杂度密切相关，它描述了模型能够表示多少种不同的函数或模式。模型容量越大，表示模型能够学习到的数据的复杂性和多样性就越多。

1️⃣ **模型容量的定义**

模型容量是衡量一个模型能够学习和逼近不同类型函数的能力。具体来说，它与以下因素密切相关：

- **模型的结构**：例如，神经网络的层数和每层的神经元数量。对于同一种任务，一个深度神经网络的容量通常比浅层网络更大，因为深度网络能学习到更复杂的特征表示。
- **模型的自由度**：模型中的参数数量（如权重和偏差的数量）。模型的自由度越多，它的容量就越大。
- **非线性变换的数量**：神经网络中的激活函数（如ReLU、Sigmoid等）增加了模型的非线性表达能力，因此，更多的非线性变换通常意味着更高的模型容量。

2️⃣ **模型容量与过拟合、欠拟合的关系**

模型容量直接影响模型的拟合能力：

- **低容量模型（欠拟合）**：如果模型容量太小，它无法表示训练数据中的复杂模式，可能导致欠拟合。一个低容量的模型可能太简单，无法捕捉到数据的真实规律。
- **高容量模型（过拟合）**：如果模型容量过大，它能够拟合训练数据中的噪声和不规则性，导致过拟合。一个高容量的模型能够学习到很多不同的模式，因此在训练数据上可能表现得非常好，但在测试数据上泛化能力差。

3️⃣ **如何衡量模型容量？**

- **参数数量**：模型的参数数量（如神经网络中的权重）直接影响模型容量。参数越多，模型容量通常越大。例如，一个深度神经网络比浅层神经网络的参数多，因此它的容量更大。
- **层数和神经元数**：在神经网络中，层数（深度）和每层的神经元数量（宽度）都影响模型的容量。增加层数或者每层的神经元数通常会增加模型的容量，因为它增加了模型对数据的表示能力。
- **非线性函数的数量**：非线性激活函数使得模型能够学习到更复杂的决策边界，因此网络中的激活函数也增加了模型的容量。

##### 1.3.3.1 模型容量估计

单隐藏层模型的容量，通常指的是该模型中**可训练参数的总数量**。对于一个具有单隐藏层的神经网络，容量的计算主要取决于输入层到隐藏层之间、隐藏层到输出层之间的权重矩阵和偏差项的数量。

1️⃣ **设定：**

- ddd：输入特征数（例如，对于一个输入是28x28像素的图像，d=28×28=784d = 28 \times 28 = 784d=28×28=784）。
- mmm：隐藏层神经元的数量。
- kkk：输出类别数。
- +1+1+1 表示每层神经网络的**偏置项（bias）**。

2️⃣ **计算过程：**

1. **输入层到隐藏层的权重和偏差**：

   - 输入层有 d 个特征，隐藏层有 m 个神经元，因此从输入到隐藏层的权重矩阵大小是 $d \times m$，包含 $d \times m$ 个权重参数。
   - 每个隐藏层的神经元都有一个偏置项，因此隐藏层有 m 个偏置参数。

   所以，**输入层到隐藏层的总参数数**是：$d \times m + m$

   其中，$d \times m$ 是权重参数，m 是偏置参数。

2. **隐藏层到输出层的权重和偏差**：

   - 隐藏层有 m 个神经元，输出层有 k 个类别，因此从隐藏层到输出层的权重矩阵大小是 $m \times k$，包含 m$m \times k$ 个权重参数。
   - 每个输出层的神经元也有一个偏置项，因此输出层有 k 个偏置参数。

   所以，**隐藏层到输出层的总参数数**是：$m \times k + k$

   其中，$m \times k$ 是权重参数，k 是偏置参数。

3. **总参数数**： 将输入层到隐藏层的参数和隐藏层到输出层的参数相加，得到整个模型的总参数数：
   $$
   (d \times m + m) + (m \times k + k)
   $$
   也可以写作：
   $$
   (d + 1) \times m + (m + 1) \times k
   $$
   其中：

   - $(d + 1) \times m$ 是输入层到隐藏层的总参数数（包含偏置项）。
   - $(m + 1) \times k$ 是隐藏层到输出层的总参数数（包含偏置项）。

3️⃣ **解释：**

- $d$：输入特征的维度（例如，图像的像素数）。
- $m$：隐藏层神经元的数量，通常决定了模型的**容量**，即它能够学习的复杂度。
- $k$：输出类别数，例如二分类任务时 k=2k = 2k=2。
- $+1$：每一层（输入到隐藏层、隐藏层到输出层）都有一个偏置项，它与输入和输出的维度无关，但对于每个神经元都需要一个额外的参数。

4️⃣ **举个例子：**

假设你有一个输入特征数 $d = 784$（比如28x28的图像），隐藏层神经元数量 $m = 256$，输出类别数 $k = 10$（例如，MNIST的分类任务）。那么模型的参数数目是：
$$
(784 + 1) \times 256 + (256 + 1) \times 10 = 785 \times 256 + 257 \times 10= 201,760 + 2,570 = 204,330
$$
所以，模型的**总参数数**是204,330个。

5️⃣ **总结：**

单隐藏层神经网络的**参数容量**是模型能够学习的参数总数，包括了输入到隐藏层的权重和偏置、隐藏层到输出层的权重和偏置，计算公式为：

$(d + 1) \times m + (m + 1) \times k$

这个数量直接影响模型的学习能力，模型容量越大，理论上能学习的函数复杂度越高，但也容易导致过拟合。

#### 1.3.4 VC维

**VC 维（Vapnik-Chervonenkis Dimension）**，是机器学习理论中的一个重要概念，用来度量一个学习模型或假设空间的**表达能力**或**复杂度**。VC 维反映了模型能够“区分”不同数据集的能力。它是由 **Vapnik** 和 **Chervonenkis** 在20世纪60年代提出的，主要用于**监督学习**中的分类问题。

1️⃣ **VC 维的定义**

VC 维是指一个学习模型或假设空间中，能够被该模型“完美区分”的最大数据集的大小。

更具体地说，假设你有一个数据集 $S = \{x_1, x_2, \dots, x_n\}$ 及其对应的标签。我们称这个数据集是**可分割的**（shatterable），如果存在某个假设空间中的模型，使得模型能够根据数据集中的每个样本，正确地为其分配标签。对于一个假设空间，如果对于某个大小的数据集，我们可以找到足够多的分类方式使其完全可分割，那么该空间的VC维就至少是这个大小。

VC 维的定义可以简化为：“VC 维是一个假设空间可以完美分割的最大数据点的数量”。

2️⃣ **VC 维的公式**

我们一般说，假设空间的 **VC 维是 d**，则表示：

- 在该假设空间中，能够找到一个大小为 d 的数据集，使得对于这个数据集的所有可能的标签分配（即所有可能的类别组合），假设空间都能够实现分类（完美区分）。
- 但是，若数据集的大小超过了 d，则可能存在一些标签分配是该假设空间无法实现的。

3️⃣ **VC 维的直观理解**

- **低 VC 维**：如果模型的VC 维很小，意味着该模型的表达能力有限，只能解决一些简单的问题。例如，线性分类器的 VC 维较小，它只能分割线性可分的数据集。
- **高 VC 维**：如果模型的 VC 维很大，表示该模型能够表达复杂的决策边界，能够适应更复杂的数据集。例如，多层神经网络通常具有较高的 VC 维。

4️⃣ **VC 维与模型复杂度的关系**

VC 维的大小与模型的复杂度直接相关：

- **高 VC 维**：意味着模型具有较强的学习能力，可以适应复杂的数据，但同时也容易过拟合，因为模型可能会过度学习训练数据中的噪声和细节。
- **低 VC 维**：意味着模型的学习能力较弱，可能无法有效拟合训练数据中的模式，从而导致欠拟合。

5️⃣ **VC 维与泛化能力**

VC 维与模型的泛化能力密切相关：

- **泛化能力强**：如果一个模型的 VC 维适中，它能有效学习训练数据的模式，但也能在测试集上进行良好的预测。
- **过拟合（模型复杂度过高）**：如果 VC 维太大，模型的复杂度太高，容易在训练数据上表现很好，但在新的未见数据上表现不佳，因为它对训练数据的噪声和细节进行了过度拟合。
- **欠拟合（模型复杂度过低）**：如果 VC 维太小，模型的复杂度不足以捕捉数据的潜在模式，无法在训练数据上做出准确预测，从而导致欠拟合。

6️⃣ **VC 维与学习的可行性**

- 在 **统计学习理论**中，VC 维与学习问题的可行性有着紧密联系。根据 **VC 不等式**（VC inequality），我们可以估计一个模型的训练误差和泛化误差之间的差距，从而理解模型在实际数据上的表现。
- **VC 维与训练集大小**：VC 维越高，通常需要更多的训练样本来保证泛化能力，否则会出现过拟合。

7️⃣ **VC 维的计算例子**

假设你有一个 **线性分类器**，它的任务是将二维平面中的点分为两类。对于二维空间，线性分类器的 VC 维是 **3**。因为我们可以找到一个包含3个点的数据集，它在二维空间中是可以被线性分割的，并且任何3个点的标签组合都可以通过线性分割来实现。对于4个点的数据集，无论如何标签分配，都不能保证能够线性分割。

8️⃣ **VC 维与深度学习**

在深度学习中，神经网络通常具有较高的 VC 维。虽然它们能够拟合复杂的训练数据，但也容易出现过拟合问题。因此，训练深度神经网络时，通常会使用 **正则化** 技术（如 L2 正则化、dropout 等）来限制模型的复杂度，从而提高其泛化能力。

9️⃣ **总结**

VC 维是一个衡量模型能力的重要指标。它与模型的学习能力、过拟合、欠拟合等问题密切相关。理解 VC 维对于选择合适的模型和调节模型的复杂度、训练样本的大小等方面有重要的指导意义。

通过 **VC 维**，我们能够：

- 衡量一个模型的复杂度。
- 理解一个模型是否能够有效学习训练数据，并且能够泛化到新的数据集上。

- 这里设置了多项式的最大阶数为20，并且为训练集和测试集各生成100个样本。
- `true_w` 是用于生成标签的多项式的真实权重，只有前4项有值，其他项为零。

接下来，随机生成特征数据，并根据多项式计算标签。并且为了防止过大的数值，使用 `gamma` 函数调整每一项。

```python
features = np.random.normal(size=(n_train + n_test, 1))  # 生成特征
np.random.shuffle(features)  # 打乱顺序
poly_features = np.power(features, np.arange(max_degree).reshape(1, -1))  # 生成特征的幂次项
for i in range(max_degree):
    poly_features[:, i] /= math.gamma(i + 1)  # gamma(n)=(n-1)!
```

- `features`：我们用正态分布生成了训练集和测试集的特征数据。
- `poly_features`：对这些特征做多项式扩展，将特征升高到不同的幂次。
- 为了防止指数项带来的数值过大，我们使用 `math.gamma(i+1)` 进行缩放。
- `np.power(features, np.arange(max_degree).reshape(1, -1))`利用了广播机制，生成一个二维矩阵，每一行是对应输入的第 $j$ 次幂，$j$ 从 $0$ 到 max_degree-1

然后，使用生成的多项式特征计算标签，并添加一些噪声。

```python
labels = np.dot(poly_features, true_w)  # 计算标签
labels += np.random.normal(scale=0.1, size=labels.shape)  # 加入噪声
```

- `np.dot(poly_features, true_w)`：计算每个特征向量和真实权重的点积，生成标签。
- `np.random.normal(scale=0.1)`：添加一个标准差为0.1的噪声项。

4️⃣ **定义损失函数**

我们定义了一个用于评估模型损失的函数。

```python
def evaluate_loss(net, data_iter, loss):
    """评估给定数据集上模型的损失"""
    metric = d2l.Accumulator(2)  # 损失的总和,样本数量
    for X, y in data_iter:
        out = net(X)
        y = y.reshape(out.shape)
        l = loss(out, y)
        metric.add(l.sum(), l.numel())
    return metric[0] / metric[1]
```

- `evaluate_loss` 函数接收模型、数据迭代器和损失函数作为输入。
- 在每个迭代过程中，计算模型输出 `out` 和标签 `y` 之间的损失 `l`。
- 使用 `d2l.Accumulator` 进行损失和样本数量的累加，最终返回平均损失。

5️⃣ **定义训练函数**

我们接下来定义了训练过程的函数。

```python
def train(train_features, test_features, train_labels, test_labels, num_epochs=400):
    loss = nn.MSELoss(reduction='none')  # 均方误差损失
    input_shape = train_features.shape[-1]  # 输入特征的维度
    net = nn.Sequential(nn.Linear(input_shape, 1, bias=False))  # 定义一个线性回归模型
    batch_size = min(10, train_labels.shape[0])  # 设置批次大小
    train_iter = d2l.load_array((train_features, train_labels.reshape(-1, 1)), batch_size)  # 加载训练数据
    test_iter = d2l.load_array((test_features, test_labels.reshape(-1, 1)), batch_size, is_train=False)  # 加载测试数据
    trainer = torch.optim.SGD(net.parameters(), lr=0.01)  # 使用SGD优化器
    animator = d2l.Animator(xlabel='epoch', ylabel='loss', yscale='log', xlim=[1, num_epochs], ylim=[1e-3, 1e2], legend=['train', 'test'])
    for epoch in range(num_epochs):
    	d2l.train_epoch_ch3(net, train_iter, loss, trainer)  # 训练一轮
    	if epoch == 0 or (epoch + 1) % 20 == 0:
        	animator.add(epoch + 1, (evaluate_loss(net, train_iter, loss), 
                                     evaluate_loss(net, test_iter, loss)))  	  # 绘制损失图
    print('weight:', net[0].weight.data.numpy())  # 打印训练得到的权重
```

- `loss`：定义了均方误差（MSE）损失。
- `net`：定义了一个线性模型（`nn.Linear`），用于进行线性回归。
- `train_iter` 和 `test_iter`：加载训练和测试数据集。
- `trainer`：使用 Stochastic Gradient Descent（SGD）优化器来更新模型参数。
- `animator`：用于绘制训练过程中损失的变化图。
- 训练过程中，我们调用 `d2l.train_epoch_ch3` 完成每一轮的训练。
- 每训练20轮，就绘制一次训练集和测试集上的损失变化曲线。
- 最后，输出训练后的模型权重。

# 七、正则项与正则化

## 1、正则项

**正则项（Regularization Term）** 是机器学习中用于防止模型过拟合的一种技术，通过在损失函数中添加一个与模型参数相关的额外项，对参数值进行约束，从而提升模型的泛化能力。其核心思想是**以略微增加训练误差为代价，显著降低测试误差**。

---

✅ **1. 正则项的作用**

- **防止过拟合**：限制模型参数的大小，避免模型过度依赖训练数据中的噪声或异常值。
- **控制模型复杂度**：简单的模型（参数值较小）通常泛化能力更强。
- **特征选择**（如L1正则化）：通过稀疏化参数自动筛选重要特征。

---

✅ **2. 正则项的数学形式**

在原始损失函数 $ J(\mathbf{w}) $ 的基础上，添加正则项 $R(\mathbf{w})$：
$$
J_{\text{正则化}}(\mathbf{w}) = J(\mathbf{w}) + \lambda R(\mathbf{w})
$$


-  $\mathbf{w}$ ：模型参数（如神经网络的权重）。
- $\lambda$ ：**正则化系数**，控制正则化的强度（$\lambda \geq 0$）。
- $R(\mathbf{w})$ ：正则化项，常见形式如下：

| 正则化类型   | 公式 $R(\mathbf{w})$                                         | 效果                   |
| ------------ | ------------------------------------------------------------ | ---------------------- |
| **L1正则化** | $\|\mathbf{w}\|_1 = \sum\|w_i\|$                             | 稀疏化参数（特征选择） |
| **L2正则化** | $\frac{1}{2}\|\mathbf{w}\|_2^2 = \frac{1}{2}\sum w_i^2$      | 平滑参数（权重衰减）   |
| **弹性网**   | $\alpha \|\mathbf{w}\|_1 + \frac{1-\alpha}{2}\|\mathbf{w}\|_2^2$ | L1和L2的混合           |

---

✅ **3. 正则项的工作原理**

**以L2正则化为例**

- **原始目标**：最小化损失函数 $J(\mathbf{w})$ （如均方误差）。
- **添加L2项后**：模型需同时最小化 $J(\mathbf{w})$ 和权重平方和 $|\mathbf{w}\|_2^2$。
- **结果**：权重会被压缩到较小的值，避免某些权重过大导致过拟合。

**几何解释**

- **L2正则化**：将参数限制在一个“球”形区域内（偏好均匀的小权重）。
- **L1正则化**：将参数限制在一个“菱形”区域内（偏好稀疏的零权重）。

---

✅ **4. 正则化的实际应用**

**在神经网络中**

```python
# PyTorch中的L2正则化（通过优化器的weight_decay参数）
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=0.01)  # weight_decay = λ
```

**在线性回归中**

- **Ridge回归（L2）**：
  $$
  \min_{\mathbf{w}} \| \mathbf{y} - \mathbf{X}\mathbf{w} \|^2 + \lambda \|\mathbf{w}\|_2^2
  $$
  
- **Lasso回归（L1）**：
  $$
  \min_{\mathbf{w}} \| \mathbf{y} - \mathbf{X}\mathbf{w} \|^2 + \lambda \|\mathbf{w}\|_1
  $$

---

✅ **5. 如何选择正则化类型？**

| 场景                        | 推荐正则化            | 原因                       |
| --------------------------- | --------------------- | -------------------------- |
| 需要特征选择                | L1（Lasso）           | 生成稀疏权重，自动筛选特征 |
| 高维数据（特征数 > 样本数） | 弹性网（Elastic Net） | 结合L1和L2的优势           |
| 一般防止过拟合              | L2（Ridge）           | 稳定且计算高效             |

---

✅ **6. 超参数 \( \lambda \) 的选择**

- **过大**：模型欠拟合（参数被过度压缩）。
- **过小**：正则化效果微弱，可能过拟合。
- **调参方法**：网格搜索（Grid Search）或交叉验证。

---

✅ **总结**

正则项是模型优化中的一种**约束手段**，通过惩罚复杂模型来提升泛化性能。其核心是：
1. **在损失函数中增加参数相关的惩罚项**。
2. **通过 \( \lambda \) 控制惩罚强度**。
3. **根据问题需求选择L1、L2或混合形式**。

实际应用中，正则化与Dropout、Batch Normalization等技术常配合使用，共同提升模型效果。

## 2、正则化

---

### **2.1. L2正则化（权重衰减 / Ridge回归）**
✅ **公式**
$$
J_{\text{L2}}(\mathbf{w}) = J(\mathbf{w}) + \frac{\lambda}{2} \|\mathbf{w}\|_2^2
$$
其中 $\|\mathbf{w}\|_2^2 = \sum w_i^2$

✅ **梯度更新**
$$
\frac{\partial J_{\text{L2}}}{\partial w_i} = \frac{\partial J}{\partial w_i} + \lambda w_i
$$


- **更新规则**： $w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} + \lambda w_i \right)$ 
- **效果**：权重按比例收缩（乘以 $1-\eta\lambda$），趋向于小而分散的值。

✅ **应用场景**

- 防止过拟合，通用性强。
- 适用于需要平滑权重的模型（如线性回归、神经网络）。

✅ **PyTorch实现**

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=0.01)  # weight_decay = λ
```

---

### **2.2. L1正则化（Lasso回归）**
✅ **公式**
$$
J_{\text{L1}}(\mathbf{w}) = J(\mathbf{w}) + \lambda \|\mathbf{w}\|_1
$$
其中 $\|\mathbf{w}\|_1 = \sum |w_i|$。

✅ **梯度更新（次梯度）**
$$
\frac{\partial J_{\text{L1}}}{\partial w_i} = \frac{\partial J}{\partial w_i} + \lambda \cdot \text{sign}(w_i)
$$


- **更新规则**：
  - 若 $w_i > 0$： $w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} + \lambda \right)$ 
  - 若 $w_i < 0$：$w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} - \lambda \right)$ 
  - 若 $w_i = 0$：使用次梯度（如0）。
- **效果**：产生稀疏权重（部分权重精确为0）。

✅ **应用场景**

- 特征选择（高维数据）。
- 需要模型解释性的场景（如医疗、金融）。

✅ **PyTorch实现**

```python
def l1_regularization(model, lambda_l1):
    l1_loss = sum(torch.norm(p, 1) for p in model.parameters())
    return lambda_l1 * l1_loss

loss = criterion(outputs, labels) + l1_regularization(model, 0.01)
```

---

### **2.3. 弹性网（Elastic Net）**
✅ **公式**
$$
J_{\text{Elastic Net}} = J(\mathbf{w}) + \lambda \left( \alpha \|\mathbf{w}\|_1 + \frac{1-\alpha}{2} \|\mathbf{w}\|_2^2 \right)
$$

- $\alpha$：控制L1/L2的混合比例（通常取0.5）。

✅ **梯度更新**
$$
\frac{\partial J_{\text{Elastic Net}}}{\partial w_i} = \frac{\partial J}{\partial w_i} + \lambda \left( \alpha \cdot \text{sign}(w_i) + (1-\alpha) w_i \right)
$$
✅ **应用场景**

- 高维数据且特征间存在相关性。
- 需同时进行特征选择和权重平滑。

✅ **Scikit-learn实现**

```python
from sklearn.linear_model import ElasticNet
model = ElasticNet(alpha=1.0, l1_ratio=0.5)  # alpha=λ, l1_ratio=α
```

---

### **2.4. Dropout（神经网络特有）**
✅ **原理**

- 训练时随机以概率 \(p\) 丢弃神经元，测试时使用全部神经元但缩放权重（乘以 \(1-p\)）。
- **等效正则化**：通过破坏神经网络的协同适应性，防止过拟合。

✅ **梯度更新**

- 被丢弃的神经元梯度为0，其余正常更新。

✅ **PyTorch实现**

```python
model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),  # 50%丢弃率
    nn.Linear(256, 10)
)
```

---

### **2.5. 早停法（Early Stopping）**
✅ **原理**

- 监控验证集误差，当误差不再下降时停止训练。
- **正则化效果**：限制模型训练轮数，避免过度拟合训练数据。

✅ **实现**

```python
from pytorchtools import EarlyStopping

early_stopping = EarlyStopping(patience=5)  # 容忍5轮不下降
for epoch in range(100):
    train(...)
    val_loss = validate(...)
    early_stopping(val_loss, model)
    if early_stopping.early_stop:
        break
```

---

### **2.6. 数据增强（Data Augmentation）**
✅ **原理**

- 对训练数据施加随机变换（如旋转、裁剪），增加数据多样性。
- **正则化效果**：等效于隐式扩大数据集，减少过拟合。

✅ **示例（图像）**

```python
transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),  # 随机水平翻转
    transforms.RandomRotation(10),     # 随机旋转
    transforms.ToTensor()
])
```

### **对比总结**
| 正则化类型      | 数学形式                                                     | 梯度更新特点         | 适用场景             |
| --------------- | ------------------------------------------------------------ | -------------------- | -------------------- |
| **L2**          | $\lambda \|\mathbf{w}\|_2^2$                                 | 线性收缩权重         | 通用模型，防止过拟合 |
| **L1**          | $\lambda \|\mathbf{w}\|_1$                                   | 产生稀疏解           | 特征选择，高维数据   |
| **Elastic Net** | $\lambda (\alpha \|\mathbf{w}\|_1 + (1-\alpha)\|\mathbf{w}\|_2^2)$ | 混合L1/L2效果        | 高维且相关特征的数据 |
| **Dropout**     | 随机丢弃神经元                                               | 梯度仅更新活跃神经元 | 神经网络             |
| **早停法**      | 基于验证集停止训练                                           | 无显式梯度修改       | 所有迭代模型         |
| **数据增强**    | 对输入数据随机变换                                           | 梯度来自增强样本     | 图像、文本等数据     |

---

### **如何选择？**
- **默认尝试**：L2正则化（简单高效）。
- **特征选择**：L1或弹性网。
- **神经网络**：Dropout + L2 + 早停法。
- **数据不足**：数据增强 + 早停法。

## 3、不同正则化方法对比

---

**正则化方法对比表**

| 正则化类型                         | 数学形式                                                     | 梯度更新公式                                                 | 公式元素说明                                                 |
| ---------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **L2正则化**<br>(权重衰减 / Ridge) | $J + \frac{\lambda}{2} \|\mathbf{w}\|_2^2$ <br> $|\mathbf{w}\|_2^2 = \sum w_i^2 $ | $\frac{\partial J}{\partial w_i} + \lambda w_i$              | - $\lambda$ : 正则化强度<br>- $w_i$ : 第 $i$ 个权重参数      |
| **L1正则化**<br>(Lasso)            | $J + \lambda \|\mathbf{w}\|_1$ <br>$|\mathbf{w}\|_1 = \sum \|w_i\|$ | $\frac{\partial J}{\partial w_i} + \lambda \cdot \text{sign}(w_i)$ | - $\text{sign}(w_i)$ : 符号函数（1, -1 或 0）<br>- 产生稀疏性 |
| **弹性网**<br>(Elastic Net)        | $J + \lambda \left( \alpha \|\mathbf{w}\|_1 + \frac{1-\alpha}{2} \|\mathbf{w}\|_2^2 \right)$ | $\frac{\partial J}{\partial w_i} + \lambda \left( \alpha \cdot \text{sign}(w_i) + (1-\alpha) w_i \right)$ | - $\alpha$ : L1/L2混合比例（0≤α≤1）<br>- 平衡稀疏性与平滑性  |
| **Dropout**                        | 无显式数学形式                                               | 被丢弃的神经元梯度为0，其余正常更新                          | - \( p \): 丢弃概率（如0.5）<br>- 测试时权重乘以 \( 1-p \)   |
| **早停法**                         | 无显式数学形式                                               | 无梯度修改，直接停止训练                                     | - `patience`: 容忍验证集误差不下降的轮数                     |

---

**公式元素统一说明**

1. $J$ : 原始损失函数（如交叉熵、均方误差）。
2. $\mathbf{w}$ : 模型权重向量，$w_i$ 表示第 $i$ 个权重。
3. $\lambda$: 正则化系数（超参数），控制惩罚强度：
  
   - $\lambda \uparrow$  → 正则化效果更强，可能欠拟合。
   - $\lambda \downarrow$  → 正则化效果减弱，可能过拟合。
4. * $\alpha$ : 仅在弹性网中使用，调节L1与L2的权重比例：
  
   - $\alpha=1$ → 纯L1正则化。
   - $\alpha=0$ → 纯L2正则化。
5. $\text{sign}(w_i)$ : 符号函数，定义为：
   $$
   \text{sign}(w_i) = 
   \begin{cases} 
   1 & \text{if } w_i > 0, \\
   -1 & \text{if } w_i < 0, \\
   0 & \text{if } w_i = 0.
   \end{cases}
   $$
   

---

**梯度更新示例（SGD优化器）**

假设学习率为  $\eta$ ，各正则化方法的权重更新规则如下：

| 正则化类型  | 权重更新公式                                                 |
| ----------- | ------------------------------------------------------------ |
| **L2**      | $w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} + \lambda w_i \right)$ |
| **L1**      | $w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} + \lambda \cdot \text{sign}(w_i) \right)$ |
| **弹性网**  | $w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} + \lambda (\alpha \cdot \text{sign}(w_i) + (1-\alpha) w_i) \right)$ |
| **Dropout** | 未被丢弃的神经元：$w_i \leftarrow w_i - \eta \frac{\partial J}{\partial w_i}$ |

---

**关键区别总结**

1. **L2**：平滑权重，适合通用场景。
2. **L1**：生成稀疏解，适合特征选择。
3. **弹性网**：结合L1和L2，适合高维相关数据。
4. **Dropout**：神经网络专属，随机破坏协同适应性。
5. **早停法**：通过终止训练防止过拟合，无数学惩罚项。

通过此表可快速对比不同正则化方法的核心公式和实现逻辑！

# 八、权重衰减

## 1、原理

**权重衰减（Weight Decay）** 是机器学习中一种通过惩罚模型权重的大小来防止过拟合的正则化技术，本质上是 **L2正则化** 的别名（尤其在优化器参数中）。其核心思想是通过在损失函数中添加权重的平方和（L2范数）作为惩罚项，迫使模型学习更小的权重值，从而降低模型复杂度，提升泛化能力。

---

### **1.1. 权重衰减的数学定义**
**原始损失函数**  

假设模型的目标是最小化损失函数 $J(\mathbf{w})$ （如交叉熵、均方误差），其中 $\mathbf{w}$  是权重向量。

**添加权重衰减后的损失函数**  
$$
J_{\text{new}}(\mathbf{w}) = J(\mathbf{w}) + \frac{\lambda}{2} \|\mathbf{w}\|_2^2
$$

- $\lambda$（`lambda`）：**权重衰减系数**（超参数），控制惩罚强度（$\lambda \geq 0$）。  
- $\|\mathbf{w}\|_2^2$：权重的 **L2范数平方**（即所有权重的平方和）：  
  $$
  \|\mathbf{w}\|_2^2 = \sum_{i=1}^n w_i^2
  $$
- $\frac{1}{2}$ ：为了求导后梯度形式更简洁（系数变为 $\lambda$ 而非 $2\lambda$ ）。

---

### **1.2. 权重衰减的作用**
- **防止过拟合**：抑制权重值过大，避免模型过度拟合训练数据中的噪声。
- **提高泛化性**：倾向于学习更平滑的权重分布，增强对未见数据的预测能力。
- **稳定训练**：对异常值或离群点更鲁棒。

---

### **1.3. 梯度更新（反向传播）**
权重衰减直接影响权重的梯度计算。对权重 $w_i$ 的梯度为：  
$$
\frac{\partial J_{\text{new}}}{\partial w_i} = \frac{\partial J}{\partial w_i} + \lambda w_i
$$
**随机梯度下降（SGD）的更新规则**：  
$$
w_i \leftarrow w_i - \eta \left( \frac{\partial J}{\partial w_i} + \lambda w_i \right)
$$
其中 $\eta$ 是学习率。可以改写为：  
$$
w_i \leftarrow (1 - \eta \lambda) w_i - \eta \frac{\partial J}{\partial w_i}
$$


- **直观解释**：每次更新前，权重先按比例 $(1 - \eta \lambda)$ 收缩，再进行常规梯度下降。

---

### **1.4. 在深度学习框架中的实现**
**PyTorch**  

通过优化器的 `weight_decay` 参数直接设置 $\lambda$ ：  
```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=0.01)  # λ=0.01
```

**TensorFlow/Keras**  

在优化器中指定 `weight_decay`（需根据版本调整）：  
```python
optimizer = tf.keras.optimizers.Adam(learning_rate=0.001, weight_decay=0.001)
```

---

### **1.5. 权重衰减 vs L2正则化**
- **本质相同**：权重衰减是L2正则化的优化器实现形式，数学上完全等价。  
- **术语差异**：  
  - **L2正则化**：强调在损失函数中添加惩罚项的理论视角。  
  - **权重衰减**：强调优化过程中权重逐步缩小的行为视角。

---

### **1.6. 超参数 $\lambda$ 的选择**
- $\lambda$ **过大**：权重被过度压缩，模型可能欠拟合。  
- $\lambda$ **过小**：正则化效果微弱，可能过拟合。  
- **调参建议**：  
  - 初始尝试  $\lambda \in [0.0001, 0.1]$ （对数尺度搜索）。  
  - 结合验证集性能调整。

---

### **1.7. 与其他正则化技术的对比**
| 技术         | 核心机制         | 效果                     | 适用场景                   |
| ------------ | ---------------- | ------------------------ | -------------------------- |
| **权重衰减** | 惩罚权重的L2范数 | 权重平滑，防止过拟合     | 通用模型（尤其是神经网络） |
| **L1正则化** | 惩罚权重的L1范数 | 产生稀疏权重，特征选择   | 高维数据/特征选择          |
| **Dropout**  | 随机丢弃神经元   | 破坏神经网络的协同适应性 | 神经网络                   |
| **早停法**   | 提前终止训练     | 限制训练轮数，防止过拟合 | 所有迭代模型               |

---

### **总结**
- **权重衰减 = L2正则化**，通过惩罚大权重防止模型复杂度过高。  
- **实现方式**：在优化器中设置 `weight_decay` 参数（如PyTorch/TensorFlow）。  
- **关键超参数**： $\lambda$  需通过交叉验证调优。  
- **优势**：简单高效，是深度学习中最常用的正则化手段之一。

**2.1.2. 生成合成数据**

首先，我们[**像以前一样生成一些数据**]，生成公式如下：

(**$$y = 0.05 + \sum_{i = 1}^d 0.01 x_i + \epsilon \text{ where }
\epsilon \sim \mathcal{N}(0, 0.01^2).$$**)

我们选择标签是关于输入的线性函数。
标签同时被均值为0，标准差为0.01高斯噪声破坏。
为了使过拟合的效果更加明显，我们可以将问题的维数增加到$d = 200$，
并使用一个只包含20个样本的小训练集。

```python
n_train, n_test, num_inputs, batch_size = 20, 100, 200, 5
true_w, true_b = torch.ones((num_inputs, 1)) * 0.01, 0.05
train_data = d2l.synthetic_data(true_w, true_b, n_train)
train_iter = d2l.load_array(train_data, batch_size)
test_data = d2l.synthetic_data(true_w, true_b, n_test)
test_iter = d2l.load_array(test_data, batch_size, is_train=False)
```

- `n_train`, `n_test`, `num_inputs`, `batch_size`：分别定义训练集样本数、测试集样本数、特征维度和批量大小。
- `true_w`, `true_b`：定义真实的权重和偏置，权重初始化为 `0.01`，偏置为 `0.05`，用于生成目标标签 `y`。
- `train_data` 和 `test_data`：使用 `d2l.synthetic_data()` 生成训练数据和测试数据，数据服从公式 $y = 0.05 + \sum_{i=1}^{d} 0.01 x_i + \epsilon$，其中 $\epsilon$ 是噪声。
- `train_iter` 和 `test_iter`：将生成的数据转换为 PyTorch 的数据加载器（`DataLoader`），按批次加载数据。

### 2.2 模型构建

#### 2.2.1 从零开始实现

**1、初始化模型参数**

```python
def init_params():
    w = torch.normal(0, 1, size=(num_inputs, 1), requires_grad=True)
    b = torch.zeros(1, requires_grad=True)
    return [w, b]
```

- `init_params()`：定义一个函数初始化模型的参数。
  - `w`：用正态分布（均值为 0，标准差为 1）初始化权重，大小为 `(num_inputs, 1)`，表示每个输入特征的权重。
  - `b`：初始化偏置为 0。
  - 这两个参数都设置了 `requires_grad=True`，以便计算梯度并参与反向传播。

**2、定义 L2 范数惩罚（正则化项）**

```python
def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2
```

- `l2_penalty(w)`：计算 L2 范数的惩罚项，即对权重 `w` 的每个元素进行平方求和，然后除以 2。这是常见的 L2 正则化形式，有助于减少过拟合。

**3、训练模型**

```python
def train(lambd):
    w, b = init_params()
    net, loss = lambda X: d2l.linreg(X, w, b), d2l.squared_loss
    num_epochs, lr = 100, 0.003
    animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',
                            xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            # 增加了L2范数惩罚项，
            # 广播机制使l2_penalty(w)成为一个长度为batch_size的向量
            l = loss(net(X), y) + lambd * l2_penalty(w)
            l.sum().backward()
            d2l.sgd([w, b], lr, batch_size)
        if (epoch + 1) % 5 == 0:
            animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss),
                                     d2l.evaluate_loss(net, test_iter, loss)))
    print('w的L2范数是：', torch.norm(w).item())
```

- `train(lambd)`：训练模型的函数，`lambd` 是权重衰减（L2 正则化）的超参数。

  - `w, b = init_params()`：初始化权重和偏置。
  - `net`：定义了线性回归模型（`d2l.linreg(X, w, b)`）。
  - `loss`：使用均方误差（MSE）作为损失函数。
  - `num_epochs`, `lr`：定义训练的轮数（100）和学习率（0.003）。
  - `animator`：用于可视化训练过程中的损失变化。

  在每个训练周期中：

  - 计算损失 `l`，其中包括原始损失和 L2 正则化项（`lambd * l2_penalty(w)`）。
  - `.sum().backward()`：进行反向传播，计算梯度。
  - `d2l.sgd([w, b], lr, batch_size)`：使用小批量随机梯度下降（SGD）更新权重和偏置。
  - 每 5 个 epoch 打印一次训练和测试集的损失。

  最后，打印权重 `w` 的 L2 范数。

**4、忽略正则化直接训练**

```python

```

- 这行代码禁用权重衰减（`lambd=0`）。
- **结果**：训练误差会减少，但测试误差没有降低，表明出现了过拟合。

#### 2.2.2 简单实现

**1、简洁实现**

```python
def train_concise(wd):
    net = nn.Sequential(nn.Linear(num_inputs, 1))
    for param in net.parameters():
        param.data.normal_()
    loss = nn.MSELoss(reduction='none')
    num_epochs, lr = 100, 0.003
    # 偏置参数没有衰减
    trainer = torch.optim.SGD([
        {"params":net[0].weight,'weight_decay': wd},
        {"params":net[0].bias}], lr=lr)
    animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',
                            xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            trainer.zero_grad()
            l = loss(net(X), y)
            l.mean().backward()
            trainer.step()
        if (epoch + 1) % 5 == 0:
            animator.add(epoch + 1,
                         (d2l.evaluate_loss(net, train_iter, loss),
                          d2l.evaluate_loss(net, test_iter, loss)))
    print('w的L2范数：', net[0].weight.norm().item())
```

- 这是一个更简洁的实现，使用 PyTorch 内建的优化器来处理权重衰减。
  - 通过 `torch.optim.SGD` 创建优化器，并指定 `weight_decay=wd` 来启用 L2 正则化。
  - 在训练过程中，通过 `.zero_grad()` 清空梯度，`.backward()` 计算梯度，`.step()` 更新模型参数。
  - 同时使用 `d2l.Animator` 可视化训练和测试集上的损失变化。
- `param.data.normal_()`对模型参数进行初始化

**2、运行简洁实现**

```python
train_concise(0)
train_concise(3)
```

- `train_concise(0)`：不使用权重衰减。
- `train_concise(3)`：使用权重衰减，`wd=3`。
- **结果**：与从零实现相比，这种简洁实现运行得更快，而且效果相似，展示了权重衰减对过拟合的有效控制。
